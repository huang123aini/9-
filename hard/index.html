一元二次方程

高级目标：处理根的分布、含参讨论、整数根和构造新方程。

核心模型

根与参数

  • 两正根：Δ ≥ 0，x₁+x₂ > 0，x₁x₂ > 0。
  • 两负根：Δ ≥ 0，x₁+x₂ < 0，x₁x₂ > 0。
  • 异号根：x₁x₂ < 0（此时 Δ > 0 自动成立）。
  • 两根都大于 k：令 t = x−k，转化为 t 的两个正根；或结合对称轴和端点函数值。
  • 构造方程：以 x₁+1、x₂+1 或 1/x₁、1/x₂ 为根，先求它们的和与积。
方法

含参问题的顺序

  1. 先看二次项系数：等于 0 时是一次方程，不等于 0 才是二次方程。
  2. 再算 Δ，判断有没有实根。
  3. 最后用韦达定理或求根公式，结合题目对根的限制列不等式。
含参题最怕漏情况：二次项系数、Δ、根的正负，一层一层分。
例题

3 道综合题

例 1（综合）：已知方程 x² − 2(m+1)x + m² + 5 = 0 的两根 x₁、x₂ 满足 x₁² + x₂² = 18，求 m。

看详细解析
  1. 先保证有实根：Δ = 4(m²+2m+1) − 4(m²+5) = 8m − 16 = 8(m−2)，所以 m ≥ 2。
  2. 韦达定理：x₁+x₂ = 2(m+1)，x₁x₂ = m²+5。
  3. x₁²+x₂² = 4(m+1)² − 2(m²+5) = 2m²+8m−6。
  4. 令 2m²+8m−6 = 18，得 m²+4m−12=0，即 (m+6)(m−2)=0。
  5. 结合 m ≥ 2，只取 m=2。

例 2（压轴）：关于 x 的方程 (m−1)x² − 2mx + m + 1 = 0 有两个不相等的正根，求 m 的取值范围。

看详细解析
  1. 方程是二次方程，先要求 m ≠ 1。
  2. Δ = 4m² − 4(m−1)(m+1) = 4 > 0，所以总有两个不等实根。
  3. 两根为 1 和 (m+1)/(m−1)。
  4. 两根都为正：1 > 0 已满足，只需 (m+1)/(m−1) > 0。
  5. 解得 m < −1 或 m > 1。
  6. 所以 m ∈ (−∞,−1) ∪ (1,+∞)。

例 3（提高）：已知方程 x² − 3x + m = 0 的两根 x₁、x₂ 满足 x₁² − x₂² = 3，求 m。

看详细解析
  1. 由韦达定理：x₁+x₂ = 3，x₁x₂ = m。
  2. 分解：x₁²−x₂² = (x₁−x₂)(x₁+x₂) = 3(x₁−x₂) = 3。
  3. 所以 x₁−x₂ = 1。
  4. 联立 x₁+x₂=3、x₁−x₂=1，得 x₁=2，x₂=1。
  5. 所以 m = x₁x₂ = 2。检验：Δ = 9 − 8 = 1 > 0。
易错点：忘记 Δ ≥ 0；二次项系数为 0 时仍当二次方程；根的分布只写韦达不写 Δ；构造方程时漏掉根的和与积。

二次函数

高级目标：区间最值、含参抛物线、抛物线与几何综合。

核心模型

抛物线综合

  • 区间最值：看对称轴是否在区间内，分“轴在区间左、内、右”三种情况。
  • 含参抛物线：恒过定点、顶点轨迹、判别式与交点个数。
  • 抛物线与几何：面积最大、线段和最小、存在性问题。
  • 绝对值图象：y = |ax²+bx+c| 把 x 轴下方部分翻折到上方。
  • 数形结合：方程的根 ↔ 交点横坐标；不等式解集 ↔ 图象位置。
方法

压轴题的切入口

  1. 先配方：把对称轴和顶点找出来，再讨论区间。
  2. 再画图：标出交点、顶点、对称轴，把几何条件翻译成坐标。
  3. 最后分类：参数影响开口、对称轴或区间位置时，逐一讨论。
例题

3 道综合题

例 1（综合）：已知二次函数 y = x² − 2ax + 3 在区间 [0,2] 上的最小值为 −1，求 a。

看详细解析
  1. 配方：y = (x−a)² + 3−a²，对称轴 x=a。
  2. a < 0 时，最小值在 x=0 处，y=3，不等于 −1，舍去。
  3. 0 ≤ a ≤ 2 时，最小值在顶点处：3−a² = −1，a²=4，a=2。
  4. a > 2 时，最小值在 x=2 处：7−4a = −1，a=2，不符合 a > 2。
  5. 所以 a=2。

例 2（压轴）：抛物线 y = x² − 2x − 3 与 x 轴交于 A、B（A 在左），与 y 轴交于 C。在对称轴上求一点 P，使 PA + PC 最小，求 P 的坐标。

看详细解析
  1. A(−1,0)，B(3,0)，C(0,−3)，对称轴 x=1。
  2. 因为 A、B 关于对称轴对称，所以 PA=PB，PA+PC=PB+PC。
  3. 当 B、P、C 三点共线时，PB+PC 最短。
  4. 直线 BC：y=x−3，令 x=1，得 y=−2。
  5. 所以 P(1,−2)。

例 3（提高）：抛物线 y = x² − 2x − 3 与 x 轴交于 A、B，在抛物线上找一点 P，使 △PAB 的面积为 8，求 P 的坐标。

看详细解析
  1. A(−1,0)，B(3,0)，所以 AB=4。
  2. 面积 S = ½×AB×|y| = 2|y| = 8，所以 |y|=4，y=4 或 y=−4。
  3. 当 y=4：x²−2x−3=4，即 x²−2x−7=0，x=1±2√2。
  4. 当 y=−4：x²−2x−3=−4，即 x²−2x+1=0，x=1。
  5. 所以 P 有三个：(1+2√2,4)、(1−2√2,4)、(1,−4)。
易错点：区间最值不分类；忽略自变量范围；把顶点坐标符号写错；面积问题忘记纵坐标可能为负，要加绝对值。

旋转

高级目标：用旋转构造全等、处理半角模型和旋转最值。

核心模型

旋转构造

  • 手拉手模型：两个等边三角形或正方形共顶点，旋转后得到全等三角形。
  • 半角模型：正方形中 ∠EAF=45°，旋转 90° 把 BE、DF 拼成一条线段。
  • 旋转最值：把分散线段转移到一起，用“两点之间线段最短”。
  • 等边三角形旋转：旋转 60° 常能得到新的等边三角形。
  • 坐标旋转：关于原点对称是基本型，绕任意点旋转可先平移再旋转。
方法

怎么想到旋转

  1. 看到“共顶点、等长边、特殊角（60°、90°）”，先想旋转。
  2. 确定旋转中心、旋转角和旋转方向，把分散的线段搬到一起。
  3. 旋转后找全等三角形，把要证的线段或角转化。
例题

3 道综合题

例 1（综合）：△ABC 和 △ADE 都是等边三角形，共顶点 A，且按同一方向排列。连接 BD、CE，求证 BD=CE。

看详细解析
  1. 把 △ABD 绕点 A 旋转 60°，方向与 ∠BAC 相同。
  2. AB=AC，∠BAC=60°，所以 B 旋转后落在 C。
  3. AD=AE，∠DAE=60°，所以 D 旋转后落在 E。
  4. 线段 BD 旋转后变成 CE，旋转不改变长度，所以 BD=CE。

例 2（压轴）：正方形 ABCD 的边长为 4，E、F 分别在 BC、CD 上，∠EAF=45°，求 △CEF 的周长。

看详细解析
  1. 把 △ABE 绕 A 顺时针旋转 90° 到 △ADG，则 BE=DG，AE=AG。
  2. ∠BAD=90°，∠EAF=45°，所以 ∠BAE+∠DAF=45°；又 ∠DAG=∠BAE，所以 ∠GAF=45°。
  3. △AEF 与 △AGF 中：AE=AG，AF 公共，∠EAF=∠GAF，所以全等（SAS）。
  4. EF=GF=DG+DF=BE+DF。
  5. 周长 = CE+CF+EF = (BC−BE)+(CD−DF)+(BE+DF)=BC+CD=8。

例 3（提高）：等边 △ABC 的边长为 4，D 是 BC 上一动点，将 △ABD 绕 A 逆时针旋转 60° 得到 △ACE，求 DE 的最小值。

看详细解析
  1. 旋转 60° 后，AD=AE，∠DAE=60°，所以 △ADE 是等边三角形。
  2. 因此 DE=AD，求 DE 的最小值就是求 AD 的最小值。
  3. D 在 BC 上运动，AD 最短时 D 是 BC 的中点，AD 是等边三角形的高。
  4. 高 = 4×√3/2 = 2√3，所以 DE 的最小值是 2√3。
易错点：旋转方向搞反；对应点找错；旋转后忘记说明三点共线；只写结论不写全等理由。

圆

高级目标：圆与三角形综合、隐圆、切线综合、面积最值。

核心模型

圆与综合题

  • 圆与三角形：外心是垂直平分线交点，内心是角平分线交点；直角三角形内切圆半径 r=(a+b−c)/2。
  • 隐圆：定弦定角、直角所对的斜边为直径、四点共圆。
  • 切线综合：连半径、作垂直、勾股、相似、三角函数。
  • 面积最值：定弦定角时，等腰三角形面积最大。
  • 阴影面积：割补、等积变换、扇形组合。
方法

压轴题的切入口

  1. 先连半径、作弦心距，把圆的问题变成直角三角形。
  2. 看到定弦定角，先找隐圆；看到切线，连切点半径。
  3. 求最值时，先确定动点轨迹，再找特殊位置（中点、垂直）。
例题

3 道综合题

例 1（综合）：在 Rt△ABC 中，∠C=90°，AC=3，BC=4，求外接圆半径 R 和内切圆半径 r。

看详细解析
  1. 斜边 AB=√(3²+4²)=5。
  2. 直角三角形外接圆直径是斜边，所以 R=5/2=2.5。
  3. 内切圆半径 r=(a+b−c)/2=(3+4−5)/2=1。
  4. 检验：面积=6，半周长=6，r=面积/半周长=1。

例 2（压轴）：在 △ABC 中，AB=4，∠ACB=60°，求 △ABC 面积的最大值。

看详细解析
  1. C 在以 AB 为弦的圆上运动，∠ACB=60° 固定。
  2. 当 CA=CB 时，C 在弧的中点，到 AB 的距离最大。
  3. 外接圆半径 R=(AB/2)/sin60°=4/√3。
  4. 圆心到 AB 的距离 = R cos60° = 2/√3。
  5. 最大高 = R+2/√3 = 2√3。
  6. 面积最大值 = ½×4×2√3 = 4√3。

例 3（提高）：在等腰 △ABC 中，AB=AC=5，BC=6，求它的外接圆半径。

看详细解析
  1. 作 AD⊥BC 于 D。因为 AB=AC，所以 D 是 BC 中点，BD=3。
  2. AD=√(5²−3²)=4。
  3. 设外心 O 在 AD 上，半径为 R，则 OA=OB=R，OD=|4−R|。
  4. 在 Rt△OBD 中：R² = 3² + (4−R)²。
  5. 展开：R² = 9 + 16 − 8R + R²，所以 8R=25，R=25/8。
易错点：把内心和外心混在一起；隐圆找不到；面积最大时忘记说明等腰；切线证明漏掉“经过半径外端”。

概率初步

高级目标：多步试验、不放回、跨章节综合、游戏公平性。

核心模型

概率综合

  • 多步试验：树状图分步，注意有序与无序的统一。
  • 不放回：总数递减，第二次的概率要基于第一次的结果。
  • 跨章节综合：与方程、函数、几何图形结合。
  • 游戏公平：比较双方获胜概率是否相等。
  • 几何概率：用面积比表示概率（拓展）。
方法

压轴题的切入口

  1. 先确定试验分几步，画树状图或表格。
  2. 把“至少”“至多”转化为对立事件，减少计算。
  3. 综合题先翻译成概率条件，再回到方程或函数。
例题

3 道综合题

例 1（综合）：从 −2、−1、0、1、2 中随机取一个数作为 a，从 −1、0、1 中随机取一个数作为 b，求二次函数 y=ax²+bx+1 的图象开口向下且与 x 轴有两个交点的概率。

看详细解析
  1. 共有 5×3=15 种等可能结果。
  2. 开口向下要求 a < 0，所以 a=−2 或 −1，共 2 种。
  3. Δ=b²−4a；当 a=−2 或 −1 时，Δ 都大于 0。
  4. 每种 a 有 3 种 b，所以有利结果 2×3=6 种。
  5. P=6/15=2/5。

例 2（压轴）：袋中有 3 个红球、2 个白球，甲先摸，乙后摸，摸后不放回，先摸到红球者获胜。这个游戏公平吗？

看详细解析
  1. 甲第一次摸红球的概率是 3/5，甲胜。
  2. 甲摸白球（2/5）后，乙摸红球的概率是 3/4，乙胜。
  3. 两人都摸白球的概率是 2/5×1/4=1/10，此时只剩红球，甲胜。
  4. P(甲胜)=3/5+1/10=7/10，P(乙胜)=2/5×3/4=3/10。
  5. 概率不相等，游戏不公平，对甲有利。

例 3（提高）：连续抛一枚均匀硬币三次，求至少两次正面向上的概率。

看详细解析
  1. 三次抛硬币共有 2×2×2=8 种等可能结果。
  2. 至少两次正面包括：恰好两次正面、三次正面。
  3. 恰好两次正面：正正反、正反正、反正正，共 3 种。
  4. 三次正面：正正正，1 种。
  5. 所以 P=(3+1)/8=1/2。
易错点：有序和无序混用；不放回时忘记减少总数；把频率当概率；跨章节题忘记先翻译条件。
