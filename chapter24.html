本章地图

圆的性质 → 垂径定理 → 圆周角与圆内接四边形 → 点与圆、直线与圆 → 弧长与扇形 → 正多边形与圆。

先抓住这条主线

  1. 圆的基本元素：圆心、半径、弦、直径、弧、圆心角、圆周角。
  2. 垂径定理：垂直于弦的直径平分弦，也平分弦所对的弧。
  3. 圆周角定理：同弧所对的圆周角等于圆心角的一半。
  4. 位置关系：点与圆、直线与圆，都用“距离 d 和半径 r”比较。
  5. 计算：弧长、扇形面积、正多边形的中心角与边心距。
圆里最常用的辅助线：连半径、作弦心距、连圆心和切点。

白话速览

先用一句话看懂本章

一句话：车轮为什么是圆的。 车轴到轮边的距离处处相等，所以车走起来不颠。圆的所有半径都相等。

你只要抓住 3 件事

  1. 垂径定理：看到弦，作弦心距。半径、弦心距、半弦组成直角三角形：r² = d² + (弦长/2)²。
  2. 圆周角：同弧所对的圆周角等于圆心角的一半；直径所对的圆周角是 90°；圆内接四边形对角互补。
  3. 直线与圆：d < r 相交，d = r 相切，d > r 相离。切线垂直于过切点的半径；从圆外一点引两条切线，切线长相等。

最容易踩的坑

把弦心距当半径；半弦写成整弦；看到垂直就说切线（还要经过半径外端）。

3 分钟小任务：半径 5，圆心到弦的距离 3，弦长？圆心角 100°，同弧圆周角？（点开看答案）
半弦长 = √(5² − 3²) = √16 = 4，所以弦长 = 2 × 4 = 8。同弧所对的圆周角 = 100° ÷ 2 = 50°。
24.1

垂径定理实验台：半径、弦心距、半弦

半径 r4
弦心距 d2
半弦长√12 ≈ 3.46
弦长 AB2√12 ≈ 6.93
r² = d² + (AB/2)²

过圆心 O 作弦 AB 的垂线，垂足是 M。因为 OA = OB，所以 AM = MB，这就是垂径定理。

  • 垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。
  • 连接半径 OA，得到直角三角形 OMA。
  • 三边关系：r² = d² + (AB/2)²。
注意：d 是圆心到弦的垂线段长度，不是半径；半弦是 AB/2，不是 AB。
24.1

圆周角定理：同弧所对的圆周角是圆心角的一半

圆心角 ∠AOB120°
圆周角 ∠APB60°
关系∠APB = ½ ∠AOB

圆周角的顶点在圆上，两边都与圆相交。它对着一段弧，这段弧也对着一个圆心角。

  • 同弧所对的圆周角相等，并且等于圆心角的一半。
  • 直径所对的圆周角是直角（90°）。
  • 反过来，90° 的圆周角所对的弦是直径。
移动 P，只要 P 还在同一段弧上，∠APB 就不变。点“AB 变成直径”看 90° 的特例。
24.2

直线与圆：比较 d 和 r

半径 r3.5
圆心到直线的距离 d2
位置关系相交
公共点个数2
  • d < r：直线与圆相交，有两个公共点。
  • d = r：直线与圆相切，只有一个公共点，这条线叫切线。
  • d > r：直线与圆相离，没有公共点。

切线的性质：圆的切线垂直于过切点的半径；经过半径外端并且垂直于这条半径的直线是圆的切线。

判断位置关系，先找圆心到直线的垂线段 d，再和半径 r 比较，不要凭感觉画。
24.4

弧长与扇形面积

弧长 L8.38
扇形面积 S16.76
L = nπr / 180
S = nπr² / 360 = ½ Lr

把圆看成 360° 的扇形。圆心角 n° 的扇形，弧长和面积都占整个圆的 n/360。

  • 整个圆的周长是 2πr，所以弧长 L = (n/360)·2πr。
  • 整个圆的面积是 πr²，所以扇形面积 S = (n/360)·πr²。
  • 扇形面积还可以写成 S = ½ Lr。
公式里的 n 是圆心角的度数，不是弧长，也不是弦长。
24.3

正多边形与圆：中心角、边心距

中心角60°
内角120°
边长4
边心距3.46

正 n 边形的顶点都在同一个圆上，这个圆叫它的外接圆。圆心也是正多边形的中心。

  • 中心角：360°/n。
  • 内角：(n−2)·180°/n。
  • 半径 R、边心距 a、半边长 R·sin(π/n) 组成直角三角形：R² = a² + (边长/2)²。
正六边形的中心角是 60°，可以分成 6 个等边三角形，是正多边形里最特殊的一个。

24.2

点与圆的位置关系

设点到圆心的距离为 d，圆的半径为 r：

  • d < r：点在圆内。
  • d = r：点在圆上。
  • d > r：点在圆外。
判断点和圆的位置，只看“点到圆心的距离”和半径的大小关系。
24.1

圆内接四边形

四个顶点都在同一个圆上的四边形，叫圆内接四边形。

∠A + ∠C = 180°，∠B + ∠D = 180°

也就是说，圆内接四边形的对角互补；它的一个外角等于与它相对的内角（内对角）。

看到“圆内接四边形”，先想“对角加起来是 180°”。
24.2

切线长定理与三角形的心

从圆外一点引圆的两条切线，切线长相等，圆心与该点的连线平分两条切线的夹角。

PA = PB，∠APO = ∠BPO

三角形的内切圆圆心是三条角平分线的交点，叫内心；外接圆圆心是三边垂直平分线的交点，叫外心。

24.4

圆锥的侧面展开图

圆锥的侧面展开后是一个扇形：扇形的半径是母线 l，弧长是底面圆的周长 2πr。

S侧 = πrl
S全 = πrl + πr²
先找母线 l 和底面半径 r，再套公式；不要和扇形面积公式混用。

用

日常里的圆

车轮、井盖、披萨、拱桥、摩天轮，圆的性质就在身边。

生活 · 井盖

井盖为什么做成圆形？

圆的每一条直径都相等，边缘到圆心的距离都相等。

d = 2r（所有方向都一样）

圆形井盖无论怎么转，都不会掉进井口。

正方形井盖沿对角线方向可能掉下去；圆的“等宽”性质让它更安全。

美食 · 扇形

12 寸披萨切成 8 块

每块是一个扇形，圆心角是 360° ÷ 8 = 45°。

S = 45/360 × πr² = 1/8 πr²

每块面积是整个披萨的 1/8。

扇形面积与圆心角成正比：角度翻倍，面积也翻倍。

建筑 · 拱桥

拱桥的半径怎么求？

桥拱跨度 20 m，拱高 4 m。设半径 r，则 r² = (r−4)² + 10²。

r² = r² − 8r + 16 + 100
8r = 116 → r = 14.5 m

拱桥所在圆的半径是 14.5 m。

这是垂径定理的典型应用：半径、弦心距、半弦组成直角三角形。

游乐 · 摩天轮

12 个座舱的摩天轮

座舱均匀分布在圆周上。

360° ÷ 12 = 30°

相邻座舱与圆心连线的夹角是 30°。

座舱到圆心的距离都等于半径，转起来才平稳。

运动 · 中圈

篮球场的中圈

中圈是一个圆，开球时双方球员站在圈外。

C = 2πr

知道半径就能算周长；知道周长也能反求半径。

圆上的点到圆心距离相等，所以中圈对双方是公平的。

机械 · 齿轮

齿轮的齿为什么均匀分布？

齿轮的齿绕中心等角分布，才能平稳啮合。

每个齿的中心角 = 360°/齿数

齿数越多，每个齿对应的中心角越小。

这和正多边形的中心角是同一个道理。

高频易错点

圆里的错误，多半是“把线段认错了”。

五个高频错误

  1. 把弦心距当半径：d 是圆心到弦的垂线段，r 是半径。
  2. 半弦写成整弦：勾股关系里用的是 AB/2，不是 AB。
  3. 圆周角顶点不在圆上：顶点必须在圆上，两边都要与圆相交。
  4. 看到垂直就说是切线：还要经过半径外端。
  5. 弧长公式用错角：n 是圆心角的度数，不是弦长，也不是圆周角。

辅助线口诀

  • 有弦，作弦心距；连半径，出直角三角形。
  • 有直径，想直角；有直角，想直径。
  • 有切线，连圆心和切点，得垂直。
  • 有正多边形，连中心和顶点，得中心角。
  • 求弧长、扇形面积，先找圆心角和半径。
圆的问题，先画图，再把已知量标到图上，最后找直角三角形或等腰三角形。
