本章地图

单项式与多项式 → 同类项 → 去括号 → 合并同类项 → 整式加减与化简求值。

先抓住这条主线

  1. 整式的分类：单项式是数与字母的积（单独一个数或字母也是单项式）；几个单项式的和叫多项式。
  2. 次数：单项式看所有字母指数的和；多项式看次数最高的项。
  3. 同类项：所含字母相同，并且相同字母的指数也相同。
  4. 合并同类项：系数相加，字母和指数不变。
  5. 去括号：括号前是正号，直接去；括号前是负号，括号里每一项都变号。
看到长式子，先标同类项，再去括号，最后合并。顺序乱了就容易丢负号。

白话速览

先用一句话看懂本章

一句话：同类项才能合并，括号前有负号就全员变号。 合并时只加系数，字母部分照抄。

你只要抓住 3 件事

  1. 同类项：3x 与 −5x 是同类项；3x 与 3x² 不是，因为指数不同。
  2. 合并：3x + 2x = 5x；系数相加，字母和指数不变。
  3. 去括号：a − (b − c) = a − b + c；括号前是负号，里面每一项都变号。

最容易踩的坑

3a + 2b 不能合并；2(x + 3) = 2x + 6，不是 2x + 3；去括号只变第一项。

3 分钟小任务：化简 3x + 2y − x + 4y 与 2(x + 3) − (x − 1)（点开看答案）
3x + 2y − x + 4y = 2x + 6y；2(x + 3) − (x − 1) = 2x + 6 − x + 1 = x + 7。
难度进阶

中等难度版 / 高等难度版

基础看懂了，再用这两版往上走：中等版练化简求值，高等版练“与某字母无关”和整体思想。

中等难度版 · 会做常规题

重点方法
  • 识别：单项式的系数包括前面的符号；多项式的项也包括符号。
  • 同类项：字母相同、相同字母的指数相同，与系数无关。
  • 合并：系数相加，字母和指数不变；系数为 0 时，这一项消失。
  • 去括号：括号前是负号，括号里每一项都变号；有系数时先分配。
  • 化简求值：先化简到最简，再代入数值，能减少计算量。
典型题

化简 3(2x² − xy) − 2(3x² − 2xy)。

看答案
去括号：6x² − 3xy − 6x² + 4xy。合并同类项：x² 项抵消，xy 项是 −3xy + 4xy = xy。所以结果是 xy。

高等难度版 · 冲击压轴题

综合模型
  • 无关项：合并后令某字母的系数为 0，求出参数。
  • 整体代入：把 x² + x 或 a + b 看成一个整体。
  • 看错符号：把“减去一个多项式”写成“加上”，结果会整体反号。
  • 多项式加减：先加括号，再去括号，注意每一项都要处理。
  • 规律探究：用整式表示图形面积、周长，再化简。
挑战题

若多项式 (2x² + ax − y + 6) − (2bx² − 3x + 5y − 1) 的值与 x 无关，求 a、b。

看答案
先去括号合并： (2 − 2b)x² + (a + 3)x − 6y + 7。要与 x 无关，x² 和 x 的系数都必须为 0：2 − 2b = 0，所以 b = 1；a + 3 = 0，所以 a = −3。
4.1

先认清：单项式与多项式

3x²单项式：系数 3，次数 2
−2xy单项式：系数 −2，次数 2
3x² − 2x + 5多项式：三项，最高次是 2
名称关键点例子
单项式数与字母的积；单独一个数或字母也是单项式3x² 的系数是 3，次数是 2
多项式几个单项式的和；每一项都包括前面的符号3x² − 2x + 5 有三项
整式单项式和多项式统称整式3x²、x + 1 都是整式
判断次数：单项式看所有字母指数的和；多项式看次数最高的项。系数要带上符号。
4.2

同类项分拣机：同款的才能放一起

3x + 2y − x + 4y
= 2x + 6y
x 的系数3 + (−1) = 2
y 的系数2 + 4 = 6

同类项必须同时满足：字母相同，并且相同字母的指数也相同。

  • 3x 与 −x 是同类项；3x 与 3x² 不是。
  • 2y 与 4y 是同类项；2y 与 2xy 不是。
  • 合并时只把系数相加，字母和指数照抄。
把系数拖到 0，看看对应的项是不是消失了。系数为 0 的项通常不写。
4.2

去括号：括号前的数要乘每一项

3(x + 2) − 2(x − 1)
第 1 / 5 步

先看原式

两个括号，前面分别是 3 和 −2。去括号时，要把外面的数乘到括号里的每一项。

每一步在做什么
3(x + 2) − 2(x − 1)
3x + 6 − 2(x − 1)
3x + 6 − 2x + 2
(3x − 2x) + (6 + 2)
x + 8
括号前是 −2，乘括号里的 −1 时，负负得正，所以最后是 +2。
去括号两步检查：外面乘了几项？括号前是负号吗？
4.2

整式加减竖式：同类项对齐再算

当前运算P + Q
结果4x² + 2x + 2

整式加减的实质：去括号 → 合并同类项。竖式只是把同类项对齐，避免漏项。

  • 加法：直接把同类项的系数相加。
  • 减法：先把减号后面的多项式每一项都变号，再相加。
  • 缺项要补 0，例如没有 x 项就写 0x。
P − Q 中，Q 的每一项都要变号，不是只变第一项。
把 Q 的系数拖成 0，观察结果里对应的项如何消失。
总结

整式加减的三步流程

步骤动作检查点
1. 去括号括号前的数乘每一项；括号前是负号，每一项变号有没有漏乘？符号有没有全变？
2. 找同类项字母相同、指数相同3x 与 3x² 不是同类项
3. 合并系数相加，字母和指数不变系数为 0 的项要消失
化简求值题先化简再代入，不要一上来就把数代进去算。
用

生活里的整式

周长、面积、总价、剩余量，写成式子以后都要“合并同类项”。

购物 · 总价

买 3 本笔记本和 2 支笔，再退掉 1 本笔记本

笔记本每本 a 元，笔每支 b 元。

3a + 2b − a = 2a + 2b

实际总价是 (2a + 2b) 元。

3a 与 −a 是同类项，合并得 2a；2b 没有同类项，照抄。

几何 · 周长

长是 2x + 1，宽是 x − 3 的长方形

周长 = 2[(2x + 1) + (x − 3)]。

= 2(3x − 2) = 6x − 4

周长是 (6x − 4)。

先合并括号里的同类项，再把 2 乘进去。

面积 · 拼接

两个长方形拼在一起

左边面积 3x，右边面积 2x，拼成一个长条。

3x + 2x = 5x

总面积是 5x。

形状不同，但只要表示的是同一个量（面积），就可以合并。

剩余 · 减法

原有 5a + 3 元，花掉 a − 1 元

剩余 = 原有 − 花掉。

(5a + 3) − (a − 1) = 5a + 3 − a + 1 = 4a + 4

还剩 (4a + 4) 元。

减去一个多项式，要把括号里每一项都变号。

速度 · 路程

先骑 2 小时，再骑 3 小时

速度是 v km/h。

2v + 3v = 5v

总路程是 5v km。

2v 与 3v 是同类项，合并后表示“一共骑了 5 小时”。

数字 · 表示

一个两位数，十位数字是 a，个位数字是 b

两位数的值 = 十位数字 × 10 + 个位数字。

10a + b

这个两位数是 (10a + b)。

a、b 是数字，a 不能为 0；10a 与 b 不是同类项，不能继续合并。

应用题列式后，先化简再代入；化简后的式子往往能直接看出“每增加 1 会变化多少”。

高频易错点

整式加减的丢分，八成集中在“漏乘”和“漏变号”。

五个高频错误

  1. 乱合并：3a + 2b 不能合并成 5ab。
  2. 指数看错：3x 与 3x² 不是同类项。
  3. 漏乘：2(x + 3) = 2x + 6，不是 2x + 3。
  4. 漏变号：a − (b − c) = a − b + c。
  5. 减法整体变号：P − Q 中，Q 的每一项都要变号。

每天 20 分钟怎么练

  • 用 5 分钟做 5 道同类项判断题。
  • 用 10 分钟做 5 道化简题，每题标出“去括号”和“合并”两步。
  • 用 5 分钟检查符号：括号前是负号吗？每一项都乘了吗？
  • 把错题按“漏乘 / 漏变号 / 乱合并”分类。
