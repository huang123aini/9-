开场白

一杯热水，为什么会慢慢变凉？

冬天摸铁栏杆，觉得比摸木头冷得多；妈妈一炒菜，香味就飘满整个屋子。这些天天发生的小事，背后都藏着一群看不见的“小家伙”——分子。

它们一直在运动，温度越高越活跃。这一章，我们就从这些现象出发，弄明白“热”到底是什么、内能从哪里来，以及怎样用 Q = cmΔt 算出热量。

先想一想：同样多的水和油，用同样的火加热，谁先热起来？

本章地图

分子热运动 → 内能 → 改变内能的两种方式 → 比热容 → 热量计算。

先抓住这条主线

  1. 分子热运动：物质由分子构成，分子永不停息地做无规则运动。
  2. 扩散现象：不同物质相互接触时彼此进入对方，温度越高扩散越快。
  3. 内能：物体内所有分子热运动的动能与分子势能的总和。
  4. 改变内能：做功和热传递，两种方式等效。
  5. 比热容：单位质量物质温度升高 1℃ 吸收的热量，水的比热容较大。
  6. 热量计算：Q = cmΔt，注意 Δt 是温度变化量。
看到“闻到香味”“墨水扩散”“糖溶解”，先想到分子热运动，再想到温度。

13.1

扩散实验：温度越高，分子跑得越快

冷水分子 墨水分子 温度
温度20℃
分子运动较慢
扩散程度0%

墨水分子进入水中，水分子也进入墨水中，彼此进入对方，这就是扩散现象。

  • 扩散说明：分子在不停地做无规则运动。
  • 温度越高，分子热运动越剧烈，扩散越快。
  • 扩散可以在气体、液体、固体之间发生。
扩散不是“被风吹散”，也不是化学反应。它靠的是分子自身的无规则运动。
13.2

做功改变内能：压缩气体，温度升高

气体分子 活塞 温度升高
气体体积较大
气体温度20℃
内能较小
能量转化—

压缩活塞时，外界对气体做功，气体的内能增加，温度升高；气体膨胀时，气体对外做功，内能减少，温度降低。

  • 做功改变内能：机械能 ↔ 内能。
  • 对物体做功，物体内能增加；物体对外做功，内能减少。
  • 热传递改变内能：能量从高温物体传到低温物体，或从同一物体的高温部分传到低温部分。
柴油机的压缩冲程就是靠压缩空气使温度升高，达到柴油的着火点。
13.3

比热容：同样加热，谁升温慢

水（c = 4.2×10³） 煤油（c ≈ 2.1×10³）
吸收热量0 J
水的温度20℃
煤油的温度20℃
谁升温快—

质量相同的水和煤油，吸收相同的热量，煤油的温度升高得更快。这说明水的比热容更大。

  • 比热容 c：单位质量物质温度升高 1℃ 吸收的热量。
  • 水的比热容是 4.2×10³ J/(kg·℃)，在常见物质中较大。
  • 比热容是物质的一种属性，与质量、温度变化无关。
同种物质在不同状态下的比热容可能不同，例如水和冰的比热容不同。
13.4

热量计算器：Q = cmΔt

物质水
比热容 c4.2×10³ J/(kg·℃)
吸收热量 Q2.52×10⁵ J
折合252 kJ
Q = cmΔt

Q 是吸收或放出的热量，c 是比热容，m 是质量，Δt 是温度变化量。

  • 吸热升温：Δt = t末 − t初。
  • 放热降温：Δt = t初 − t末，结果取正值。
  • 单位要统一：m 用 kg，c 用 J/(kg·℃)，Q 的单位才是 J。
不要把 Δt 当成末温。题目说“升高到 60℃”和“升高了 60℃”完全不同。
13.5

温度、内能、热量别混淆

三者有关系，但不是同一个概念。

概念含义是否状态量常见说法
温度表示物体的冷热程度是“今天很热”“水温 60℃”
内能所有分子热运动动能与分子势能的总和是“物体具有内能”
热量热传递过程中转移的内能多少否，是过程量“吸收热量”“放出热量”
一切物体都有内能，0℃ 的冰也有内能。温度升高，内能一定增加；但内能增加，温度不一定升高，例如晶体熔化时温度不变。

取暖 · 热传递

热水袋暖手

2 kg 的水从 80℃ 降到 40℃，放出多少热量？

Q = cmΔt = 4.2×10³ × 2 × 40 = 3.36×10⁵ J

放出约 3.36×10⁵ J 的热量。

热量从高温的水传给低温的手，直到温度相同，这就是热平衡。

海边昼夜温差小

同样受太阳照射，海水和沙石的温度变化不同。

海水升温慢、降温也慢，所以海边昼夜温差较小。

高频易错点

这些地方错一次，就在错题本上写一次“错因”。

五个高频错误

  1. 说物体“含有热量”：热量是过程量，只能说吸收或放出多少热量。
  2. Δt 算错：升温用末温减初温，降温用初温减末温，结果取正值。
  3. 把比热容当成热量：比热容是物质的属性，不随质量、温度变化。
  4. 认为 0℃ 物体没有内能：一切物体都有内能，0℃ 的冰也有。
  5. 温度不变就认为内能不变：晶体熔化时温度不变，但内能增加。

练习建议

  • 先判断是“做功”还是“热传递”改变内能。
  • 热量计算先写公式，再统一单位，最后代入。
  • 遇到“升高到”和“升高了”，先在题目上圈出关键词。
  • 用比热容解释生活现象时，先说 c 的大小，再说 Δt 的大小。
  • 自己画一张“温度—内能—热量”关系图。
热学题的关键不是套公式，而是先判断能量从哪里来、到哪里去。
