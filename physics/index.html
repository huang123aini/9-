公式速查

公式要连同“适用条件”和“单位”一起记。

热学

Q = cmΔt
吸热或放热；Δt 是温度变化量，不是末温。单位：J。
Q放 = mq
燃料完全燃烧放热；q 是热值，单位 J/kg。气体用 Q = Vq。
η = W有用 / Q放 × 100%
热机效率；W有用 是有用的机械能，Q放 是燃料放出的总热量。
c水 = 4.2 × 10³ J/(kg·℃)
水的比热容较大，常用于冷却和调节气温。

电学

I = U / R
欧姆定律；同一导体、同一状态。单位：A、V、Ω。
W = UIt = Pt
电功；1 kW·h = 3.6 × 10⁶ J。
P = UI = I²R = U²/R
后两式只适用于纯电阻电路。
Q = I²Rt
焦耳定律，适用于所有电路；纯电阻电路中 Q = W。
串联：I 相等，U 相加，R 相加
R串 = R₁ + R₂；U₁/U₂ = R₁/R₂。
并联：U 相等，I 相加
1/R并 = 1/R₁ + 1/R₂；总电阻小于任一分电阻。
单位先统一再代入：cm → m、g → kg、mA → A、kW → W、min → s。单位不统一，是电学计算最常见的失分点。

四个实验方法

九上物理的实验题，几乎都绕不开这四种方法。

控制变量法

研究一个物理量与多个因素的关系时，只改变一个因素，其余因素保持不变。

  • 研究电阻与长度、横截面积、材料的关系。
  • 研究电流与电压、电阻的关系。
  • 研究扩散快慢与温度的关系。
答题时写清楚“控制什么不变，改变什么，观察什么”。

转换法

把不容易直接观察的量，转换成容易观察的现象。

  • 分子热运动 → 扩散现象。
  • 电流 → 灯泡发光、电流表偏转。
  • 电热 → 温度计示数或火柴被点燃。
  • 电阻大小 → 电流表示数或灯泡亮度。
转换法不改变研究对象，只是换一种“看得见”的方式。

类比法

用水流类比电流，用水压类比电压，用阀门类比开关，用管道阻力类比电阻。

  • 水压使水流动，电压使电荷定向移动。
  • 水管越细、越长，阻力越大；导线越细、越长，电阻越大。
类比只是帮助理解，不能把水的所有性质都套到电上。

理想模型与图像法

用图像描述规律，比死记文字更可靠。

  • I–U 图像：过原点的直线，斜率是 1/R。
  • I–R 图像：电压一定时是双曲线的一支。
  • 晶体熔化图像：有固定的熔化温度。
  • 看图像先看横纵坐标，再看起点、斜率和交点。
图像题先读坐标轴和单位，再读特殊点，最后才看整体趋势。

高频易错点与练习建议

这些地方错一次，就在错题本上写一次“错因”。

八个高频错误

  1. “热量”当状态量：不能说物体“含有多少热量”，热量是过程量。
  2. 温度、热量、内能混淆：温度升高，内能一定增加；内能增加，温度不一定升高。
  3. 热机效率算成 100%：废气、散热、摩擦都会带走能量。
  4. 电流方向搞反：规定正电荷定向移动方向为电流方向，金属中与电子移动方向相反。
  5. 电流表并联、电压表串联：电流表串联，电压表并联。
  6. 电阻与电压电流有关：对同一导体，R 由自身性质决定，U、I 变化时 R 不变。
  7. 灯泡亮度看额定功率：亮度由实际功率决定，不由额定功率直接决定。
  8. 公式乱用：P=U²/R 只适用于纯电阻电路；非纯电阻电路只能用 P=UI。

每天 25 分钟怎么练

  • 先用 5 分钟看一个动图，自己复述“它在变什么、为什么变”。
  • 再用 10 分钟做 3 道同类题，必须写公式、代数据、带单位。
  • 最后用 10 分钟整理错因：是概念错、单位错，还是电路看错。
  • 每周画一次知识结构图，把热学和电学的公式各串成一条线。
  • 遇到电路题，先画等效电路图，再标已知量和未知量。
