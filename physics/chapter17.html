开场白

电流、电压、电阻，到底谁决定谁？

电压越大，电流越大；电阻越大，电流越小。这听起来像常识，但到底大多少？能不能用一个公式算出来？

这一章，我们用实验和图像找出三者之间的定量关系，学会用一只电压表和一只电流表测出未知电阻，还会发现一个反直觉的结论：两只灯泡串联时，额定功率大的那只反而不一定更亮。

先想一想：如果电压加倍、电阻也加倍，电流会怎么变？

本章地图

I–U 图像 → I–R 关系 → 欧姆定律 → 伏安法测电阻 → 串并联规律。

先抓住这条主线

  1. 欧姆定律：I = U/R，同一导体、同一状态。
  2. I–U 图像：电阻一定时，I 与 U 成正比，图像是过原点的直线。
  3. I–R 关系：电压一定时，I 与 R 成反比。
  4. 伏安法测电阻：R = U/I，电压表并联、电流表串联。
  5. 串联：R总 = R₁ + R₂，电流相等，电压相加。
  6. 并联：1/R总 = 1/R₁ + 1/R₂，电压相等，电流相加。
用欧姆定律时先确认“同一段导体”和“同一时刻”，不能把不同导体的 U、I、R 混用。

17.1

I–U 图像：电阻一定时，电流与电压成正比

电阻 R10 Ω
电压 U6.0 V
电流 I = U/R0.60 A
直线斜率0.10 A/V

电阻不变时，电压增大，电流也按比例增大。I–U 图像是一条过原点的直线。

  • 斜率等于 1/R：电阻越大，直线越平缓。
  • 图像过原点：U = 0 时 I = 0。
  • 不同电阻的 I–U 直线斜率不同。
I–U 图像是直线，说明 I 与 U 成正比；但只有在电阻不变时才能这样说。
17.2

I–R 关系：电压一定时，电流与电阻成反比

电压 U6.0 V
电阻 R10 Ω
电流 I0.60 A
结论I 与 R 成反比

保持电压不变，增大电阻，电流减小。I–R 图像是双曲线的一支，不是直线。

  • R 变为原来的 2 倍，I 变为原来的 1/2。
  • 图像不会与坐标轴相交，因为 R 不能为 0。
  • 这个实验要用控制变量法：控制 U 不变。
“I 与 R 成反比”的前提是电压一定。电压变了，结论就不成立。
17.3

伏安法测电阻：R = U/I

电流表示数 I0.20 A
电压表示数 U2.0 V
计算电阻 R = U/I10.0 Ω
真实电阻 Rₓ10 Ω

用电压表测出 Rₓ 两端电压 U，用电流表测出通过 Rₓ 的电流 I，再由 R = U/I 算出电阻。

  • 电流表串联，电压表并联在 Rₓ 两端。
  • 滑动变阻器用来改变电流和电压，便于多次测量。
  • 多次测量求平均值，可以减小误差。
计算出的 R = U/I 是这段导体的电阻，不是“电压越大电阻越大”。移动滑片时 U、I 都变，但它们的比值不变。
17.4

串并联规律：等效电阻怎么算

连接方式串联
等效电阻 R总30 Ω
总电流 I0.20 A
U₁ / U₂2.0 V / 4.0 V
I₁ / I₂0.20 A / 0.20 A

串联总电阻等于各电阻之和；并联总电阻的倒数等于各电阻倒数之和。

  • 串联：R总 = R₁ + R₂，总电阻大于任一分电阻。
  • 并联：1/R总 = 1/R₁ + 1/R₂，总电阻小于任一分电阻。
  • 串联分压，并联分流。
并联总电阻不是两个电阻相加。两个电阻并联，总电阻比其中任何一个都小。
17.5

欧姆定律的使用条件

同一段导体、同一状态，三个量必须对应。

公式含义适用条件
I = U/R电流由电压和电阻决定同一段导体，同一状态
U = IR导体两端电压等于电流乘电阻同上
R = U/I用电压和电流的比值计算电阻测量和计算电阻，不表示 R 由 U、I 决定
欧姆定律的“同体性”和“同时性”：U、I、R 必须属于同一段导体，并且是同一时刻的值。

日常里的欧姆定律

调光、测电阻、分压分流，都离不开 I = U/R。

安全 · 电阻

为什么不能湿手碰开关

人体潮湿后电阻变小，通过人体的电流变大。

I = U/R，R ↓ → I ↑

电流变大，触电危险增加。

安全用电的原则是不接触低压带电体，不靠近高压带电体。

高频易错点

这些地方错一次，就在错题本上写一次“错因”。

五个高频错误

  1. 把不同导体的量混用：I、U、R 必须属于同一段导体。
  2. 认为 R 与 U、I 有关：R = U/I 是计算式，不是决定式。
  3. 单位不统一：mA 要换成 A，kΩ 要换成 Ω。
  4. 并联总电阻算成相加：并联总电阻小于任一分电阻。
  5. 伏安法连接错误：电流表串联、电压表并联，滑动变阻器一上一下。

练习建议

  • 做题先画等效电路图，标出已知量和未知量。
  • 串联题先求总电阻，再求电流，最后分电压。
  • 并联题先确定电压相等，再分别求各支路电流。
  • 图像题先看坐标轴，再算斜率，斜率是 1/R。
  • 计算完检查单位，电流用 A，电压用 V，电阻用 Ω。
欧姆定律题的关键是“先找同一段导体”，再决定用哪个公式。
