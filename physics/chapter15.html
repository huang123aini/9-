电流和电路

电荷的定向移动形成电流。电路有通路、断路和短路三种状态，串联和并联是两种基本连接方式。

开场白

电，到底是怎么“流”的？

按下开关，灯就亮了；脱毛衣时，噼里啪啦冒火花。电看不见、摸不着，却能让灯泡发光、让手机充电、让风扇转起来。

这一章，我们跟着电荷走一遍电路：电流从哪里来、往哪里去，串联和并联有什么不同，又为什么绝对不能把电池两极直接用导线连起来。

先想一想：为什么一串彩灯里坏了一个灯泡，整串都不亮了？

本章地图

电荷 → 电流 → 电路组成 → 三种状态 → 串联并联 → 电流表。

先抓住这条主线

  1. 两种电荷：正电荷和负电荷，同种排斥、异种吸引。
  2. 摩擦起电：实质是电子从一个物体转移到另一个物体。
  3. 电流：电荷定向移动形成，规定正电荷定向移动方向为电流方向。
  4. 电路组成：电源、用电器、开关、导线。
  5. 三种状态：通路、断路、短路，电源短路很危险。
  6. 串联并联：串联一条路径，并联多条路径。
  7. 电流表：串联接入，电流从“+”进、“−”出。
看电路先找电源，再顺着导线找电流路径，最后判断用电器是否在路径上。

15.1

摩擦起电：电子从一个物体跑到另一个物体

实验材料玻璃棒和丝绸
电子转移方向—
玻璃棒不带电
丝绸不带电

两种不同物质相互摩擦，电子从束缚能力弱的物体转移到束缚能力强的物体，使两个物体带上等量异种电荷。

  • 玻璃棒与丝绸摩擦：玻璃棒失去电子带正电，丝绸得到电子带负电。
  • 橡胶棒与毛皮摩擦：橡胶棒得到电子带负电，毛皮失去电子带正电。
  • 同种电荷相互排斥，异种电荷相互吸引。
摩擦起电不是创造电荷，而是电荷的转移。电荷的总量保持不变。
15.2

电路的三种状态：通路、断路、短路

电路状态通路
电流情况有电流
灯泡发光
电源正常

通路：处处连通的电路，有电流。断路：某处断开的电路，没有电流。短路：电流不经过用电器，直接构成回路。

  • 开关断开、导线断了、接触不良，都会造成断路。
  • 电源短路时电流很大，可能烧坏电源，甚至引起火灾。
  • 用电器短路时，该用电器不工作，其余部分可能仍工作。
绝对不能用导线把电源两极直接连起来。短路不是“电路短一点”，而是电流绕过了用电器。
15.3

串联与并联：两条不同的电流路径

连接方式串联
电流路径一条
灯泡 L₁发光
灯泡 L₂发光
开关作用控制整个电路

串联电路中只有一条电流路径，任何一个开关断开，整个电路都断路；并联电路有多条路径，各支路可以独立工作。

  • 串联：电流处处相等，I = I₁ = I₂。
  • 并联：干路电流等于各支路电流之和，I = I₁ + I₂。
  • 家庭电路中的用电器大多是并联的，一个坏了不影响其他。
节日小彩灯常常串联，一个灯坏了整串都不亮；家庭里的灯和插座是并联的。
15.4

电流表：串联接入，先看量程再读数

量程0–0.6 A
分度值0.02 A
示数0.30 A
连接方式串联

电流表必须与被测用电器串联，电流从“+”接线柱流入，从“−”接线柱流出。

  • 0–0.6 A 量程，每小格 0.02 A。
  • 0–3 A 量程，每小格 0.1 A。
  • 被测电流不能超过量程；不能把电流表直接接在电源两极上。
读数前先确认量程，再确认分度值。指针位置相同，不同量程的示数不同。
15.5

串联与并联对比

判断连接方式，最可靠的方法是“顺着电流路径走一遍”。

比较项目串联并联
电流路径只有一条有两条或多条
开关作用一个开关控制整个电路干路开关控制整个电路，支路开关控制本支路
用电器关系一个断路，全部停止工作各支路独立工作，互不影响
电流规律I = I₁ = I₂I = I₁ + I₂
生活实例节日小彩灯、部分开关与灯家庭电路中的用电器
判断串联还是并联，不要看元件画得整不整齐，要看电流有没有分岔。

高频易错点

这些地方错一次，就在错题本上写一次“错因”。

五个高频错误

  1. 摩擦起电是创造电荷：不是创造，是电子转移，电荷总量不变。
  2. 电流方向弄反：规定正电荷定向移动方向为电流方向，金属中与电子移动方向相反。
  3. 把短路当成通路：短路时电流绕过用电器，电源可能被烧坏。
  4. 电流表并联：电流表必须串联，并联会短路并损坏电表。
  5. 串联、并联判断错：看电流是否分岔，不看元件摆放位置。

练习建议

  • 画电路图时先画电源，再画干路，最后画支路。
  • 连接实物图时，导线不要交叉，开关要断开。
  • 读电流表先看量程，再算分度值，最后读数。
  • 判断串并联时，用不同颜色笔描出电流路径。
  • 遇到短路题，先找“电流不经过用电器”的那条路径。
电路题最稳的做法：先画等效电路图，再标电流方向，最后判断状态。
