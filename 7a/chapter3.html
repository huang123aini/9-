本章地图

用字母表示数 → 规范地写代数式 → 把文字翻译成式子 → 代入求值 → 用式子发现规律。

先抓住这条主线

  1. 字母表示数：字母可以表示任意数，也可以表示变化的量。
  2. 书写规范：a×b 写成 ab，1×a 写成 a，a÷b 写成分数。
  3. 列代数式：先找关键词“多、少、倍、分、和、差、积、商”。
  4. 求值：先代入，再按“乘方 → 乘除 → 加减”的顺序计算。
  5. 规律探究：从具体数字出发，用含 n 的式子表示第 n 个图形。
看到“每个”“一共”“剩余”“比……多”，先想：谁是变量，谁是常量，它们之间是什么运算。

白话速览

先用一句话看懂本章

一句话：字母是“会变的数”。 用 n 表示正方形个数，就能用 3n + 1 表示火柴棒的根数。

你只要抓住 3 件事

  1. 字母能表示数：单价 a 元、边长 x cm、速度 v km/h，都可以用字母代替。
  2. 式子会“说话”：2x + 3 表示“x 的 2 倍再加 3”。
  3. 求值有顺序：先代入，再算乘方，最后算乘除和加减；负数代入要加括号。

最容易踩的坑

a×b 写成 ab，不写 a·b；1×a 写成 a，不写 1a；a÷3 写成 a/3，不用除号。

3 分钟小任务：用含 n 的式子表示“比 n 的 2 倍少 3”，并求 n = 5 时的值（点开看答案）
式子是 2n − 3。当 n = 5 时，2 × 5 − 3 = 10 − 3 = 7。
难度进阶

中等难度版 / 高等难度版

基础看懂了，再用这两版往上走：中等版练列式与求值，高等版练规律和整体代入。

中等难度版 · 会做常规题

重点方法
  • 列式：先设字母，再按“先乘除后加减”的关系写式子，必要时加括号。
  • 书写：数字写在字母前面；带分数写成假分数；除法写成分数线。
  • 求值：把字母换成数，负数加括号，再按运算顺序计算。
  • 整体代入：已知 x² + x = 3，求 2x² + 2x + 1 时，把 x² + x 看成一个整体。
  • 几何应用：周长、面积、体积公式都是用字母表示的代数式。
典型题

当 x = −2 时，求 3x² − 2x + 1 的值。

看答案
先代入：3 × (−2)² − 2 × (−2) + 1 = 3 × 4 + 4 + 1 = 12 + 4 + 1 = 17。

高等难度版 · 冲击压轴题

综合模型
  • 图形规律：先数前三个，找“每次增加多少”，再写成 an + b。
  • 整体代入：不求出单个字母，直接把已知整体换进去。
  • 含绝对值：先判断字母的取值范围，再化简。
  • 方案比较：两种收费方式分别列式，再比较大小。
  • 探索规律：平方数、三角形数、奇数和，都可以用含 n 的式子表示。
挑战题

用含 n 的式子表示 1 + 3 + 5 + … + (2n − 1)，并验证 n = 10 时的结果。

看答案
前 n 个奇数之和等于 n²。当 n = 10 时，1 + 3 + 5 + … + 19 = 10² = 100。
3.1

火柴棒规律：每多一个正方形，多几根？

3 × 3 + 1 = 10 根
正方形个数3 个
火柴棒根数10 根
规律3n + 1

第 1 个正方形用 4 根；以后每多一个正方形，只需要再添 3 根（右、上、下）。

4 + 3(n − 1)
= 3n + 1

也可以这样想：n 个正方形单独摆需要 4n 根，但相邻的边重合了 n − 1 条，所以是 4n − (n − 1) = 3n + 1。

先数具体数，再找“每次增加多少”，最后写成含 n 的式子。这是所有规律题的通用路径。
3.2

用字母表示长方形的周长和面积

周长 = 2(a + b) = 18
面积 = ab = 18
长6
宽3

周长和面积都是用字母表示的代数式：C = 2(a + b)，S = ab。

  • 周长是一次式，面积是二次式（a 与 b 相乘）。
  • 数字与字母相乘，数字写在前面：2a，不是 a2。
  • 不同类的量不能合并：2a + 2b 不能写成 4ab。
把 a、b 换成具体的数，就能求出周长和面积；这就是“代数式求值”的几何版本。
3.3

代数式求值：先代入，再按顺序算

2x² − 3x + 1
= 2 × (−2)² − 3 × (−2) + 1
当前 x−2
代数式的值15

求值三步：代入 → 按顺序计算 → 写结果。代入负数时一定要加括号，否则乘方会算错。

  • 先算乘方，再算乘除，最后算加减。
  • 2 × (−2)² = 2 × 4 = 8，不是 (2 × −2)²。
  • 同一个代数式，x 取不同的值，结果也不同。
看到 −x²，先算 x²，再取相反数；看到 (−x)²，先把 −x 看成底数。

生活里的代数式

只要一个量会变，就可以用字母表示它，再把关系写成式子。

购物 · 总价

买 3 本笔记本和 2 支笔

笔记本每本 a 元，笔每支 b 元。

3a + 2b

总价是 (3a + 2b) 元。

3a 和 2b 不是同类项，不能合并成 5ab。

几何 · 周长

长比宽多 3 cm 的长方形

设宽为 x cm，长就是 (x + 3) cm。

周长 = 2[x + (x + 3)] = 4x + 6

周长是 (4x + 6) cm。

先用 x 表示长，再代入周长公式，最后去括号、合并。

行程 · 路程

速度 v km/h，行驶 t 小时

路程 = 速度 × 时间。

s = vt

行驶的路程是 vt km。

v、t、s 都是字母，但它们表示不同的量，不能随意相加。

规律 · 图形

用小棒摆三角形

第 1 个三角形用 3 根，以后每多一个增加 2 根。

第 n 个：3 + 2(n − 1) = 2n + 1

第 n 个图形用 (2n + 1) 根小棒。

先数 n = 1、2、3 的情况，再找每次增加的量。

折扣 · 价格

原价 x 元，打八折

八折就是原价的 80%。

0.8x

折后价是 0.8x 元。

百分数、小数和分数可以互相转化，列式时选最方便的形式。

年龄 · 关系

小明今年 m 岁，爸爸比他大 28 岁

爸爸的年龄 = 小明的年龄 + 28。

m + 28

爸爸今年 (m + 28) 岁。

5 年后，小明 m + 5 岁，爸爸 m + 33 岁，两人仍然相差 28 岁。

生活中的代数式，重点不是算出唯一答案，而是把“关系”写清楚。关系写对了，代入任何数都能算。

高频易错点

代数式的错误，多半不是不会算，而是关系写反了、括号漏了。

五个高频错误

  1. 顺序写反：“比 x 少 3”是 x − 3，不是 3 − x。
  2. 漏括号：“x 与 3 的和的 2 倍”是 2(x + 3)，不是 2x + 3。
  3. 书写不规范：a × 3 写成 3a，不写 a3；1 × a 写成 a。
  4. 代入不加括号：x = −2 时，x² 要写成 (−2)²。
  5. 不同类合并：3a + 2b 不能合并，它们表示不同的量。

每天 20 分钟怎么练

  • 用 5 分钟把 5 句中文翻译成代数式。
  • 用 10 分钟做 6 道求值题，必须写出代入那一步。
  • 用 5 分钟检查：括号、符号、运算顺序。
  • 把容易写反的句子记在错题本上，例如“少 3”和“3 少”。
