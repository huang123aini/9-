第 1 章

有理数

核心问题：有了负数以后，数轴上的点怎么表示？两个数怎么比大小？

白话速览

先用一句话看懂本章

一句话：数轴是一把有方向的尺子。 0 是起点，正数向右，负数向左；离 0 越远，绝对值越大。

你只要抓住 3 件事

  1. 数的范围扩大了：有理数包括正有理数、0、负有理数；整数和分数统称有理数。
  2. 数轴三要素：原点、正方向、单位长度。右边的数总比左边的大。
  3. 相反数与绝对值：a 与 −a 关于 0 对称；|a| 是点到 0 的距离，永远不小于 0。

最容易踩的坑

0 既不是正数也不是负数；−a 不一定是负数；绝对值等于 3 的数是 ±3。

3 分钟小任务：−(−3)、|−5|、比较 −2 和 −5（点开看答案）
−(−3) = 3；|−5| = 5；在数轴上 −2 在 −5 的右边，所以 −2 > −5。两个负数比较，绝对值大的反而小。
难度进阶

中等难度版 / 高等难度版

基础看懂了，再用这两版往上走：中等版覆盖常规题，高等版练绝对值与分类讨论。

中等难度版 · 会做常规题

重点方法
  • 分类：正数、负数、0；整数、分数。注意 0 是整数，也是有理数。
  • 数轴：先画原点、正方向、单位长度，再描点；距离原点几个单位，绝对值就是几。
  • 相反数：只改符号，a + (−a) = 0；0 的相反数是 0。
  • 绝对值：|a| = a (a ≥ 0)，|a| = −a (a < 0)。
  • 比较大小：正数 > 0 > 负数；两个负数，绝对值大的反而小。
典型题

已知 |a| = 3，|b| = 2，且 a < b，求 a、b。

看答案
a = ±3，b = ±2。要满足 a < b，a 只能取 −3，b 可以取 2 或 −2。所以 (a, b) = (−3, 2) 或 (−3, −2)。

高等难度版 · 冲击压轴题

综合模型
  • 非负性：|a| ≥ 0；若 |a| + |b| = 0，则 a = b = 0。
  • 符号化简：先判断绝对值里面式子的正负，再去绝对值符号。
  • 距离模型：|a − b| 就是数轴上 a、b 两点之间的距离。
  • 分类讨论：点的位置不确定时，按“在原点的左边 / 右边”或“在线段上 / 延长线上”分情况。
  • 最值：|x − a| + |x − b| 的最小值是 a、b 两点之间的距离。
挑战题

求 |x − 1| + |x + 3| 的最小值。

看答案
把 |x − 1| 看成 x 到 1 的距离，|x + 3| 看成 x 到 −3 的距离。点 x 在 −3 与 1 之间时，两段距离之和最小，等于 1 − (−3) = 4。所以最小值是 4，此时 −3 ≤ x ≤ 1。

正数和负数：0 是一条分界线

当前温度−6 °C
数的类别负数
实际意义零下 6 摄氏度

温度计上 0 °C 是分界线：0 以上记为正，0 以下记为负。海拔、收支、盈亏也是同样的道理。

  • 大于 0 的数叫正数，小于 0 的数叫负数。
  • 0 既不是正数，也不是负数。
  • 负号表示“相反的方向”，不是“变小”。
不要看到负号就说“这是负数”。−a 的符号取决于 a 本身：a = −2 时，−a = 2 是正数。

数轴实验台：相反数与绝对值

点 A 表示的数2
相反数 A′−2
绝对值 |a|2

数轴三要素：原点、正方向、单位长度。点 A 与它的相反数 A′ 到原点 O 的距离相等，方向相反。

  • 相反数：只改变符号，a + (−a) = 0。
  • 绝对值：点到原点的距离，|a| ≥ 0。
  • 距离原点越远，绝对值越大；与在原点左边还是右边无关。
把点拖到 0，观察：0 的相反数还是 0，|0| = 0。0 是唯一一个相反数等于本身的数。

−2 > −4

数轴上右边的数总比左边的大。所以比较大小最稳的方法，是先把它放到数轴上。

  • 正数 > 0 > 负数。
  • 两个正数，绝对值大的大。
  • 两个负数，绝对值大的反而小。
a − b > 0 等价于 a > b；a − b = 0 等价于 a = b。这也是以后学不等式的基础。

第 2 章

有理数的运算

核心问题：负数参与运算以后，符号怎么定？顺序怎么排？

白话速览

先用一句话看懂本章

一句话：先定符号，再算绝对值。 加减看方向，乘除看符号，乘方看指数是奇还是偶。

你只要抓住 3 件事

  1. 加法：同号相加，取相同符号，绝对值相加；异号相加，取绝对值大的符号，用大绝对值减小绝对值。
  2. 减法：a − b = a + (−b)。减去一个数，等于加上它的相反数。
  3. 乘除与乘方：同号得正，异号得负；负数的偶次幂为正，奇次幂为负。

最容易踩的坑

−2² 和 (−2)² 不一样；0 没有倒数；减去负数会变大；混合运算顺序不能乱。

3 分钟小任务：−3 + 5、−3 − (−5)、(−2)³、−2²（点开看答案）
−3 + 5 = 2；−3 − (−5) = −3 + 5 = 2；(−2)³ = −8；−2² = −(2²) = −4。注意：−2² 的底数是 2，(−2)² 的底数是 −2。
难度进阶

中等难度版 / 高等难度版

基础看懂了，再用这两版往上走：中等版练混合运算，高等版练符号讨论与巧算。

中等难度版 · 会做常规题

重点方法
  • 运算顺序：先乘方，再乘除，最后加减；有括号先算括号里面。
  • 运算律：加法交换律、结合律；乘法交换律、结合律、分配律，能简算就简算。
  • 除法：除以一个不为 0 的数，等于乘它的倒数。
  • 科学记数法：a × 10ⁿ，其中 1 ≤ |a| < 10，n 是正整数。
  • 近似数：精确到哪一位，就看那一位的后一位，四舍五入。
典型题

计算 −2² + (−3)² − (−4)。

看答案
先算乘方：−2² = −4，(−3)² = 9。原式 = −4 + 9 − (−4) = −4 + 9 + 4 = 9。

高等难度版 · 冲击压轴题

综合模型
  • 符号讨论：含字母的乘方，先分底数为正、为负、为 0。
  • 巧算：凑整、裂项、分组，例如 1 − 2 + 3 − 4 + …。
  • 绝对值运算：先去绝对值符号，再按顺序计算。
  • 科学记数法比较：先看 10 的指数，指数大的数更大。
  • 规律探究：观察幂的个位数字、符号变化周期。
挑战题

计算 1 − 2 + 3 − 4 + … + 99 − 100。

看答案
把相邻两项分组：(1 − 2) + (3 − 4) + … + (99 − 100)，每组都是 −1，一共有 50 组，所以结果是 −50。
2.1.1

加法实验台：先走 a，再走 b

3 + (−5) = ?
结果−2
符号法则异号相加，取绝对值大的符号

把加法看成数轴上的两次移动：从 0 出发，先走 a，再走 b，最后落到的位置就是 a + b。

  • 同号相加：方向相同，绝对值相加。
  • 异号相加：方向相反，绝对值相减，符号跟着大的走。
  • 互为相反数的两个数相加得 0。
拖动滑块，让 b 变成 −a，观察结果是不是 0。
2.1.2

减法：把“减”变成“加相反数”

2 − (−3) = 2 + 3
结果5
两点距离 |a − b|5

减去一个数，等于加上它的相反数：a − b = a + (−b)。所以减法没有新的法则，只是加法换了个写法。

  • 减去正数，结果变小；减去负数，结果变大。
  • a − b 的绝对值，就是数轴上 a、b 两点之间的距离。
  • 减法不满足交换律：a − b ≠ b − a（除非 a = b）。
符号不要连在一起读：“2 − (−3)”先变成“2 + 3”，再算 5。
2.2.1

乘法：先看符号，再算绝对值

(−3) × 4 = ?
结果−12
符号法则异号得负

乘法分两步：先判断积的符号，再把绝对值相乘。除以一个数，就是乘它的倒数。

  • 同号得正，异号得负。
  • 任何数乘 0 都得 0。
  • 几个不为 0 的数相乘，负因数有奇数个时积为负，有偶数个时积为正。
口诀：负号成双成对出现时，结果为正；落单时为负。
2.3.1

乘方：指数决定符号和增长速度

(−2)³ = ?
结果−8
符号规律负数的奇次幂为负

乘方是相同因数的乘法：aⁿ 表示 n 个 a 相乘。指数增长得很快，图上的柱子会越来越陡。

  • 正数的任何次幂都是正数。
  • 负数的偶次幂为正，奇次幂为负。
  • −a² = −(a²)，而 (−a)² = a²，底数不同。
0 的正整数次幂是 0；0 不能作除数，也没有倒数。
2.3.2

科学记数法：小数点搬了几次家

3.2 × 10⁵
320000
整数位数6 位
小数点移动向右 5 位

科学记数法写成 a × 10ⁿ，其中 1 ≤ |a| < 10。指数 n 等于原数的整数位数减 1。

例如 320000 的整数部分是 6 位，所以写成 3.2 × 10⁵；小数点从 3.2 向右移 5 位，正好还原。

理

深入原理：规则不是背出来的

知道“为什么”，才不会把符号法则、去括号、移项记混。

原理 1

为什么负负得正

3 × (−2) = −6
2 × (−2) = −4 乘数每次减少 1，积增加 2
1 × (−2) = −2
0 × (−2) = 0
(−1) × (−2) = 2

观察规律：乘数从 3 降到 2、1、0，每次都减少 1，积就每次增加 2。按照这个规律继续往下降，(−1) × (−2) 只能是 2。

从数轴看，乘 −1 就是把点翻到原点的另一侧；翻两次就回到原来那侧，所以负负得正。

这条规则保证了运算律继续成立。数学不是随便规定，而是为了让整套运算保持自洽。
原理 2

为什么减去一个数等于加上它的相反数

因为一个数加上它的相反数等于 0：

b + (−b) = 0

要计算 a − b，可以在后面加上 b + (−b)，值不变：

a − b = a − b + b + (−b) = a + (−b)

所以减法可以统一成加法，后面的运算只需要一套符号法则。

例如：

5 − (−3) = 5 + 3 = 8
−2 − 4 = −2 + (−4) = −6

减去负数会变大，减去正数会变小。方向想清楚，符号就不会乱。

“减号”和“负号”长得像，但作用不同：减号是运算，负号是数的符号。
原理 3

为什么移项要变号

x + 5 = 12
x + 5 − 5 = 12 − 5 两边同时减 5
x = 12 − 5 左边 +5 与 −5 抵消
x = 7

移项的本质，是等式两边同时加上或减去同一个数。看起来像把 +5 从左边“搬”到了右边，实际上它在两边都被减掉了。

搬到另一边后，原来的 +5 变成了 −5，所以口诀是“移项变号”。

移项不是“把数从等号左边扔到右边”，而是等式性质的一次应用。写步骤时不要跳步。
原理 4

为什么去括号要变号

括号前有负号，相当于括号整体乘以 −1：

−(a + b) = (−1) × (a + b) = −a − b

括号里的每一项都要乘 −1，所以每一项都变号。

a − (b − c) = a − b + c

括号前有系数，就用乘法分配律逐项相乘：

2(x + 3) = 2x + 6
−3(x − 2) = −3x + 6

括号里每一项都要乘，不能只乘第一项。

去括号两步检查：括号前是负号吗？括号里的每一项都变号了吗？

两地相距 60 km，两人相向而行，速度分别是 4 km/h 和 6 km/h

两人每小时靠近 4 + 6 = 10 km，设 x 小时后相遇。

(4 + 6)x = 60

x = 6，6 小时后相遇。

相遇问题：路程和 = 速度和 × 时间。画一条线段图，标出两人的位置，等量关系就很清楚。

年龄 · 方程

爸爸今年 38 岁，儿子 10 岁，几年后爸爸的年龄是儿子的 3 倍？

设 x 年后，爸爸 38 + x 岁，儿子 10 + x 岁。

38 + x = 3(10 + x)

38 + x = 30 + 3x，所以 x = 4。4 年后。

年龄问题中，两个人增加的年龄相同。列方程前先把这个“同时增加”写清楚。

钟表 · 角

3 点 30 分，时针与分针的夹角是多少？

分针指向 6，时针在 3 和 4 的正中间。

分针：180°；时针：3.5 × 30° = 105°

夹角 = 180° − 105° = 75°。

钟面被分成 12 大格，每格 30°；分针每分钟走 6°，时针每分钟走 0.5°。

一个正方体纸盒，沿棱剪开后能得到什么图形？

把立体图形展开成平面图形，六个面必须连在一起。

高频易错点与练习建议

这些地方错一次，就要在错题本上写一次“错因”。

八个高频错误

  1. 0 的身份：0 既不是正数，也不是负数。
  2. −a 的符号：−a 不一定是负数，要看 a 本身。
  3. 绝对值漏解：|x| = 3 时，x = 3 或 −3。
  4. 乘方与负号：−2² = −4，(−2)² = 4。
  5. 去括号漏乘：2(x + 3) = 2x + 6，不是 2x + 3。
  6. 去括号不变号：a − (b − c) = a − b + c。
  7. 移项不变号：从左边移到右边，符号要变。
  8. 去分母漏乘：不含分母的项也要乘最小公倍数。
