一元一次方程

把未知数放进等式，用“两边同时做同样的事”把它解出来，再用它解决实际问题。

本章地图

方程与等式性质 → 移项与合并 → 去括号 → 去分母 → 实际问题与检验。

先抓住这条主线

  1. 方程：含有未知数的等式；使等式成立的未知数的值叫方程的解。
  2. 等式性质：两边同加、同减、同乘、同除以一个不为 0 的数，等式仍成立。
  3. 解方程五步：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1。
  4. 应用题：设未知数 → 找等量关系 → 列方程 → 解方程 → 检验并写答。
  5. 检验：把解代回原方程，左右两边相等才算对。
解方程不是“变魔术”，每一步都要说得出根据：等式性质，还是分配律？

白话速览

先用一句话看懂本章

一句话：天平两边同时做同样的事，平衡不变。 方程就是天平，解方程就是不断简化，直到 x 单独站在一边。

你只要抓住 3 件事

  1. 等式性质：两边同时加减同一个数，或同时乘除同一个不为 0 的数，等式仍成立。
  2. 移项变号：把一项从等号一边移到另一边，符号要变。
  3. 去分母：两边同乘所有分母的最小公倍数，不含分母的项也要乘。

最容易踩的坑

移项忘记变号；去分母漏乘整数项；去括号漏乘；系数化为 1 时除反。

3 分钟小任务：解 2x + 3 = 11 与 3(x − 2) = 2x + 1（点开看答案）
2x + 3 = 11，移项得 2x = 8，所以 x = 4。3(x − 2) = 2x + 1，去括号得 3x − 6 = 2x + 1，移项得 x = 7。
难度进阶

中等难度版 / 高等难度版

基础看懂了，再用这两版往上走：中等版练解方程与常规应用题，高等版练方案选择和含参问题。

中等难度版 · 会做常规题

重点方法
  • 解方程：按五步走，去分母时每一项都乘，去括号时每一项都乘。
  • 移项：含未知数的项移到左边，常数项移到右边，移哪一项哪一项变号。
  • 行程：相遇用“路程和 = 速度和 × 时间”；追及用“路程差 = 速度差 × 时间”。
  • 销售：利润 = 售价 − 成本；总利润 = 单件利润 × 数量。
  • 工程：把总工作量看成 1，工作效率 = 1 ÷ 单独完成时间。
典型题

解方程 3(x − 2) = 2x + 1。

看答案
去括号：3x − 6 = 2x + 1。移项：3x − 2x = 1 + 6。合并：x = 7。检验：左边 3 × (7 − 2) = 15，右边 2 × 7 + 1 = 15，成立。

高等难度版 · 冲击压轴题

综合模型
  • 方案选择：两种收费方式分别列式，令它们相等求临界点，再分情况讨论。
  • 分段计费：不同区间单价不同，先判断落在哪一段，再列方程。
  • 含参方程：先化成 ax = b，再讨论 a 是否为 0。
  • 绝对值方程：|x − a| = b 要分 x ≥ a 和 x < a 两种情况。
  • 配套问题：先找“数量之间的倍数关系”，再列方程。
挑战题

话费方案 A：月租 30 元，每分钟 0.2 元；方案 B：无月租，每分钟 0.4 元。通话多少分钟时两种方案费用相同？

看答案
设通话 x 分钟。方案 A 费用 30 + 0.2x，方案 B 费用 0.4x。令它们相等：30 + 0.2x = 0.4x，解得 x = 150，费用都是 60 元。少于 150 分钟选 B，多于 150 分钟选 A。
5.1.2

天平实验：两边同时做同样的事

第 1 / 4 步

原来的方程

左边是 2 个 x 和 3 个 1，右边是 11 个 1，天平平衡。

2x + 3 = 11
当前操作观察天平
方程2x + 3 = 11
2x + 3 = 11
2x + 3 − 3 = 11 − 3
2x = 8
2x ÷ 2 = 8 ÷ 2
x = 4

等式性质：两边同时加、减、乘、除同一个数（除数不为 0），等式仍然成立。

第 4 步是检验：把 x = 4 代回原方程，左边 2 × 4 + 3 = 11，右边也是 11。
5.2.1

移项：过桥就要变号

第 1 / 4 步

先看原方程

未知数在两边都有，先把含 x 的项移到左边，常数项移到右边。

5x − 2 = 3x + 6
5x − 3x = 6 + 2
2x = 8
x = 4

移项的依据是等式性质：两边同时减去 3x，再同时加上 2。

  • 把 3x 从右边移到左边，变成 −3x。
  • 把 −2 从左边移到右边，变成 +2。
  • 没有移动的项不变号。
移项必须变号；只在等号同一边交换位置，不用变号。
5.2.3

去分母：每一项都要乘最小公倍数

第 1 / 6 步

先看原方程

分母是 2 和 3，最小公倍数是 6。两边每一项都要乘 6。

(x + 1)/2 − (2x − 1)/3 = 1
3(x + 1) − 2(2x − 1) = 6
3x + 3 − 4x + 2 = 6
−x + 5 = 6
−x = 1
x = −1
去分母时，分子是多项式要加括号；不含分母的项也要乘 6，不能漏掉右边的 1。
去分母是“两边同乘”，不是“把分母直接删掉”。
5.3

相遇问题：两个人什么时候碰面？

(20 + 40)t = 60
相遇时间1 小时
当前时间0 小时
两人间距60 km

相向而行时，两人每小时靠近的距离是速度和：v₁ + v₂。设 t 小时后相遇：

(v₁ + v₂)t = D

所以 t = D ÷ (v₁ + v₂)。画一条线段图，标出两人的出发点，等量关系就清楚了。

  • 相遇：路程和 = 速度和 × 时间。
  • 追及：路程差 = 速度差 × 时间。
  • 单位要统一：km 配 h，m 配 s。
拖动速度，观察相遇时间怎么变：速度和越大，相遇越快。
总结

解方程五步与应用题五步

解方程动作依据
1. 去分母两边乘所有分母的最小公倍数等式性质
2. 去括号括号外的数乘括号内每一项分配律
3. 移项含未知数的项移到左边，常数移到右边等式性质
4. 合并合并同类项，化成 ax = b合并同类项
5. 系数化 1两边除以 a，得到 x = b/a等式性质

应用题五步：设未知数 → 找等量关系 → 列方程 → 解方程 → 检验并写答。

用

生活里的一元一次方程

先找“谁和谁相等”，再把未知数设成 x，方程就出来了。

年龄 · 方程

爸爸 38 岁，儿子 10 岁，几年后爸爸是儿子的 3 倍？

设 x 年后。

38 + x = 3(10 + x)

x = 4，4 年后。

两个人增加的年龄相同，这是年龄问题的关键。

行程 · 相遇

两地相距 60 km，两人相向而行

速度分别是 20 km/h 和 40 km/h。

(20 + 40)t = 60

t = 1 小时。

相遇问题用“路程和 = 速度和 × 时间”。

销售 · 利润

一件商品进价 80 元，标价 x 元，打八折后利润 16 元

利润 = 售价 − 进价。

0.8x − 80 = 16

x = 120，标价 120 元。

打八折就是乘 0.8；利润是售价减去进价。

配套 · 数量

一张桌子配 4 把椅子，现有 12 张桌子

设需要 x 把椅子。

x = 4 × 12

需要 48 把椅子。

配套问题先找“1 张桌子配 4 把椅子”的倍数关系。

工程 · 效率

一项工程甲单独做 10 天完成，乙单独做 15 天完成

把总工作量看成 1，甲的效率是 1/10，乙是 1/15。

(1/10 + 1/15)x = 1

x = 6，合作 6 天完成。

工程问题：工作量 = 工作效率 × 时间。

方案 · 比较

两种话费方案，通话多少分钟费用相同？

A：月租 30 元 + 0.2 元/分钟；B：0.4 元/分钟。

30 + 0.2x = 0.4x

x = 150，费用都是 60 元。

先求临界点，再分“少于 150 分钟”和“多于 150 分钟”讨论。

解完方程一定要回到实际情境检验：人数不能是小数，时间不能为负，长度不能为负。

高频易错点

解方程的错误，几乎都能在“根据”上找到原因。

六个高频错误

  1. 移项不变号：从左边移到右边，符号要变。
  2. 去分母漏乘：不含分母的项也要乘最小公倍数。
  3. 去括号漏乘：括号外的数要乘括号内每一项。
  4. 去分母不加括号：分子是多项式时，乘完后要加括号。
  5. 系数化 1 除反：2x = 8 两边除以 2，得 x = 4。
  6. 应用题不检验：解出的 x 要符合实际意义。
