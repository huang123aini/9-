有理数

中级目标：会画数轴、会化简符号、会用绝对值比较大小、会处理简单的距离问题。

知识清单

先把工具摆齐

  • 分类：有理数包括正有理数、0、负有理数；整数和分数统称有理数。
  • 数轴：原点、正方向、单位长度，三要素缺一不可。
  • 相反数：a + (−a) = 0；0 的相反数是 0。
  • 绝对值：数轴上点到原点的距离，|a| ≥ 0。
  • 比较大小：数轴上右边的数总比左边的大；两个负数，绝对值大的反而小。
|a| = a（a ≥ 0）
|a| = −a（a < 0）
判断符号先问三句话：正负号是什么？绝对值是多少？它在数轴的哪一边？
方法

常规题的固定动作

  1. 画数轴：先定原点、正方向和单位长度，再描点；距离原点几个单位，绝对值就是几。
  2. 化简符号：先定符号，再去括号；−(−a) = a，−|a| 先算绝对值再取相反数。
  3. 比较大小：能画数轴就画数轴；两个负数比较，先算绝对值。
  4. 绝对值方程：|x − a| = b（b > 0）表示到 a 的距离是 b，通常有两个解。
  5. 分类讨论：点的位置不确定时，按“在原点左边 / 右边”或“在线段上 / 延长线上”分情况。
例题

3 道题，从符号到距离

例 1（基础）：化简 −(−3)、−|−5|、|−2/3|。

看详细解析
  1. −(−3) 表示 −3 的相反数，结果是 3。
  2. 先算 |−5| = 5，再取相反数，所以 −|−5| = −5。
  3. |−2/3| 表示 −2/3 到原点的距离，结果是 2/3。

例 2（提高）：已知 |a| = 3，|b| = 2，且 a < b，求 a、b。

看详细解析
  1. 由 |a| = 3 得 a = 3 或 −3；由 |b| = 2 得 b = 2 或 −2。
  2. 要满足 a < b，a 只能取 −3。
  3. b 可以取 2 或 −2，都满足 −3 < −2 和 −3 < 2。
  4. 所以 (a, b) = (−3, 2) 或 (−3, −2)。

例 3（应用）：数轴上到 2 的距离是 5 的点表示什么数？

看详细解析
  1. 设这个点表示的数为 x，则 |x − 2| = 5。
  2. 到 2 的距离是 5，可能在 2 的右边，也可能在左边。
  3. 右边：x = 2 + 5 = 7；左边：x = 2 − 5 = −3。
  4. 所以答案是 7 或 −3。
易错点：0 既不是正数也不是负数；−a 不一定是负数；绝对值等于 3 的数是 ±3；两个负数比较，绝对值大的反而小；距离问题不要漏掉另一个方向。

有理数的运算

中级目标：先定符号再算数，混合运算不跳步，乘方和科学记数法不混淆。

知识清单

五种运算与顺序

  • 加法：同号相加取相同符号，绝对值相加；异号相加取绝对值大的符号。
  • 减法：a − b = a + (−b)。
  • 乘法：同号得正，异号得负；任何数乘 0 都得 0。
  • 除法：除以一个不为 0 的数，等于乘它的倒数。
  • 乘方：负数的偶次幂为正，奇次幂为负。
先乘方 → 再乘除 → 最后加减
有括号先算括号里面
科学记数法：a × 10ⁿ，其中 1 ≤ |a| < 10，n 是正整数。
方法

常规题的固定动作

  1. 先定符号：加减看方向，乘除看符号，乘方看指数的奇偶。
  2. 减法变加法：减去一个数，先写成加上它的相反数，再按加法法则算。
  3. 乘方看清底数：−2² = −4，(−2)² = 4。
  4. 混合运算：先乘方，再乘除，最后加减；同级运算从左到右。
  5. 科学记数法：先确定 a 和 n，再还原或比较；指数大的数更大。
例题

3 道题，从计算到记数

例 1（基础）：计算 −7 + 3 − (−5)。

看详细解析
  1. 先算 −7 + 3 = −4。
  2. 减去 −5 等于加上 5：−4 + 5 = 1。
  3. 所以原式 = 1。

例 2（提高）：计算 −2² + (−3)² − (−4)。

看详细解析
  1. 先算乘方：−2² = −4（底数是 2），(−3)² = 9。
  2. 原式 = −4 + 9 − (−4)。
  3. 减去 −4 等于加 4：−4 + 9 + 4 = 9。
  4. 所以原式 = 9。

例 3（应用）：地球到太阳的距离约 1.5 × 10⁸ km，写成原数；3.20 × 10⁴ 精确到哪一位？

看详细解析
  1. 1.5 × 10⁸ = 1.5 × 100000000 = 150000000 km。
  2. 3.20 × 10⁴ = 32000，最后一位 0 在百位，所以精确到百位。
  3. 科学记数法的整数位数 = n + 1；1.5 × 10⁸ 是 9 位数。
易错点：−2² 与 (−2)² 混淆；减去负数忘记变加；0 不能作除数；混合运算顺序乱；科学记数法的指数与整数位数搞反。

代数式

中级目标：会把文字关系写成代数式，会规范书写，会代入求值。

知识清单

字母表示数与求值

  • 字母表示数：字母可以表示任意数，也可以表示变化的量。
  • 书写规范：a × b = ab，1 × a = a，a ÷ 3 = a/3。
  • 列式关键词：多、少、倍、分、和、差、积、商。
  • 求值：先代入，再按“乘方 → 乘除 → 加减”的顺序计算。
  • 整体代入：把 x² + x 看成一个整体，不单独求 x。
2x² − 3x + 1
x = −2 时，值为 15
代入负数要加括号；先乘方，再乘除，最后加减。
方法

常规题的固定动作

  1. 先找关系：先写一句“谁等于谁”，再把未知量用字母表示。
  2. 注意括号：“x 与 3 的和的 2 倍”是 2(x + 3)，不是 2x + 3。
  3. 代入求值：把字母换成数，负数加括号，再按顺序算。
  4. 整体代入：已知 x² + x = 3，求 2x² + 2x + 1 时，直接整体替换。
  5. 检查书写：数字写在字母前面，除法写成分数，带分数写成假分数。
例题

3 道题，从列式到求值

例 1（基础）：用含 n 的式子表示“比 n 的 2 倍少 3”，并求 n = 5 时的值。

看详细解析
  1. n 的 2 倍是 2n，再少 3，所以式子是 2n − 3。
  2. 当 n = 5 时，2 × 5 − 3 = 10 − 3 = 7。
  3. 注意“少 3”是在 2n 的基础上减 3，不是 3 − 2n。

例 2（提高）：当 x = −2 时，求 3x² − 2x + 1 的值。

看详细解析
  1. 代入：3 × (−2)² − 2 × (−2) + 1。
  2. 先算乘方：(−2)² = 4，所以 3 × 4 = 12。
  3. 再算乘法：−2 × (−2) = 4。
  4. 原式 = 12 + 4 + 1 = 17。

例 3（应用）：用小棒摆正方形，第 1 个用 4 根，以后每多一个多用 3 根。第 n 个图形用多少根？n = 10 时呢？

看详细解析
  1. 第 1 个 4 根，以后每多一个加 3 根，所以是 4 + 3(n − 1)。
  2. 化简：4 + 3n − 3 = 3n + 1。
  3. 当 n = 10 时，3 × 10 + 1 = 31 根。
易错点：“少 3”写成 3 − 2n；漏括号；代入负数不加括号；先加减后乘方；不同类的量强行合并。

整式的加减

中级目标：会认同类项、会合并、会去括号，能把整式化简到最简。

知识清单

整式与同类项

  • 单项式：数与字母的积；系数包括符号。
  • 多项式：几个单项式的和；每一项包括前面的符号。
  • 同类项：字母相同，并且相同字母的指数也相同。
  • 合并：系数相加，字母和指数不变。
  • 去括号：括号前是负号，括号里每一项都变号。
3x + 2x = 5x
a − (b − c) = a − b + c
3a + 2b 不能合并；3x 与 3x² 不是同类项。
方法

常规题的固定动作

  1. 先去括号：括号外的数乘括号内每一项；括号前是负号，每一项都变号。
  2. 再找同类项：字母相同、指数相同，与系数无关。
  3. 合并：系数相加，字母和指数照抄；系数为 0 的项消失。
  4. 化简求值：先化简到最简，再代入数值。
  5. 检查：有没有漏乘？符号有没有全变？
例题

3 道题，从合并到化简

例 1（基础）：合并同类项 3a + 2b − a + 4b。

看详细解析
  1. a 的同类项：3a − a = 2a。
  2. b 的同类项：2b + 4b = 6b。
  3. 所以结果是 2a + 6b。

例 2（提高）：化简 2(x + 3) − (x − 1)。

看详细解析
  1. 去括号：2(x + 3) = 2x + 6；−(x − 1) = −x + 1。
  2. 原式 = 2x + 6 − x + 1。
  3. 合并：2x − x = x，6 + 1 = 7。
  4. 所以结果是 x + 7。

例 3（应用）：化简 3(2x² − xy) − 2(3x² − 2xy)。

看详细解析
  1. 去括号：6x² − 3xy − 6x² + 4xy。
  2. x² 项：6x² − 6x² = 0。
  3. xy 项：−3xy + 4xy = xy。
  4. 所以结果是 xy。
易错点：把 3a + 2b 合成 5ab；2(x + 3) 只乘第一项；去括号只变第一项；P − Q 中 Q 的项没有全变号。

一元一次方程

中级目标：五步解方程不跳步，应用题会找等量关系并检验。

知识清单

方程与等式性质

  • 方程：含有未知数的等式；使等式成立的未知数的值叫解。
  • 等式性质：两边同加、同减、同乘、同除以一个不为 0 的数，等式仍成立。
  • 解方程五步：去分母 → 去括号 → 移项 → 合并 → 系数化为 1。
  • 应用题五步：设未知数 → 找等量关系 → 列方程 → 解 → 检验并写答。
2x + 3 = 11
2x = 8 → x = 4
移项要变号；去分母时，不含分母的项也要乘最小公倍数。
方法

常规题的固定动作

  1. 去分母：两边乘所有分母的最小公倍数，分子是多项式要加括号。
  2. 去括号：括号外的数乘括号内每一项。
  3. 移项：含未知数的项移到左边，常数项移到右边，移哪一项哪一项变号。
  4. 合并：化成 ax = b，再两边除以 a。
  5. 检验：把解代回原方程，左右两边相等才算对。
例题

3 道题，从解方程到应用

例 1（基础）：解方程 2x + 3 = 11。

看详细解析
  1. 移项：2x = 11 − 3 = 8。
  2. 系数化为 1：x = 8 ÷ 2 = 4。
  3. 检验：左边 2 × 4 + 3 = 11，右边也是 11。

例 2（提高）：解方程 (x + 1)/2 − (2x − 1)/3 = 1。

看详细解析
  1. 分母 2、3 的最小公倍数是 6，两边每一项都乘 6。
  2. 3(x + 1) − 2(2x − 1) = 6。
  3. 去括号：3x + 3 − 4x + 2 = 6，合并得 −x + 5 = 6。
  4. 移项：−x = 1，所以 x = −1。
  5. 检验：左边 (0)/2 − (−3)/3 = 1，成立。

例 3（应用）：爸爸今年 38 岁，儿子 10 岁，几年后爸爸的年龄是儿子的 3 倍？

看详细解析
  1. 设 x 年后，爸爸 38 + x 岁，儿子 10 + x 岁。
  2. 等量关系：38 + x = 3(10 + x)。
  3. 去括号：38 + x = 30 + 3x。
  4. 移项合并：8 = 2x，所以 x = 4。
  5. 4 年后爸爸 42 岁，儿子 14 岁，42 = 3 × 14，符合题意。
易错点：移项不变号；去分母漏乘整数项；去括号漏乘；系数化 1 时除反；应用题不检验。

几何图形初步

中级目标：会画线段和角，会用中点、角平分线、余角补角做计算。

知识清单

线段与角

  • 图形：立体图形与平面图形；立体图形的表面可以展开成平面图形。
  • 线段：两点之间线段最短；两点之间线段的长度叫距离。
  • 中点：AM = MB = AB ÷ 2。
  • 角：1° = 60′，1′ = 60″；角平分线把角分成两个相等的角。
  • 余补角：互余两角和 90°，互补两角和 180°。
AM = MB = AB ÷ 2
∠AOC = ∠COB = ∠AOB ÷ 2
几何题先画图，把已知标在图上，再写“因为……所以……”。
方法

常规题的固定动作

  1. 先画图：把点的位置、线段长度、角度标清楚。
  2. 线段和差：看点在不在线段上；不在线段上时，考虑延长线。
  3. 中点：先找一半，再用“和”或“差”求目标线段。
  4. 角平分线：先找两个相等的角，再算和差。
  5. 余补角：抓住“和为 90° / 180°”，不要和“剩下的角”混为一谈。
例题

3 道题，从线段到钟面角

例 1（基础）：线段 AB = 10，M 是 AB 的中点，求 AM；一个角是 30°，求它的余角和补角。

看详细解析
  1. 中点把线段平分：AM = 10 ÷ 2 = 5。
  2. 余角 = 90° − 30° = 60°。
  3. 补角 = 180° − 30° = 150°。

例 2（提高）：线段 AB = 12，C 是 AB 的中点，D 在 CB 上，CD = 3，求 AD。

看详细解析
  1. C 是 AB 的中点，所以 AC = 12 ÷ 2 = 6。
  2. D 在 CB 上，CD = 3，所以 AD = AC + CD。
  3. AD = 6 + 3 = 9。

例 3（应用）：3 点 30 分，钟面上时针与分针的夹角是多少度？

看详细解析
  1. 分针指向 6，是 180°。
  2. 时针在 3 和 4 的正中间，3.5 × 30° = 105°。
  3. 夹角 = 180° − 105° = 75°。
易错点：直线不能量长度；射线只有一个端点；点可能在延长线上，要分类；余角和补角混淆；度分秒按 60 进制。
