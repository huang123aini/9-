有理数

高级目标：把绝对值看成距离，处理非负性、分类讨论和最小值问题。

核心模型

绝对值与距离

  • 距离模型：|a − b| 是数轴上 a、b 两点之间的距离。
  • 非负性：|a| ≥ 0；若 |a| + |b| = 0，则 a = b = 0。
  • 符号化简：先判断绝对值里面式子的正负，再去绝对值符号。
  • 最小值：|x − a| + |x − b| 的最小值是 a、b 两点之间的距离。
  • 分类讨论：点的位置不确定时，按原点左右、线段内外分情况。
方法

压轴题的切入口

  1. 先翻译成距离：看到 |x − a|，先想“x 到 a 的距离”。
  2. 再画数轴：把已知点和未知点标出来，观察哪一段距离最短。
  3. 最后分类：绝对值里面符号不确定时，按正负分两种情况。
非负性题先令每一部分等于 0，再解出字母；最值题先找“中间区域”。
例题

3 道综合题

例 1（综合）：求 |x − 1| + |x + 3| 的最小值。

看详细解析
  1. |x − 1| 是 x 到 1 的距离，|x + 3| 是 x 到 −3 的距离。
  2. 点 x 在 −3 与 1 之间时，两段距离之和最小。
  3. 最小值就是 1 与 −3 之间的距离：1 − (−3) = 4。
  4. 所以最小值是 4，此时 −3 ≤ x ≤ 1。

例 2（压轴）：已知 |a| = 3，|b| = 2，且 |a − b| = b − a，求 a + b。

看详细解析
  1. |a − b| = b − a 说明 a − b ≤ 0，即 a ≤ b。
  2. a = ±3，b = ±2；要满足 a ≤ b，a 只能取 −3。
  3. b 可以取 2 或 −2。
  4. a + b = −3 + 2 = −1，或 a + b = −3 + (−2) = −5。

例 3（提高）：若 |a − 2| + |b + 3| = 0，求 a − b。

看详细解析
  1. 绝对值都大于等于 0，两个非负数相加等于 0，只能各自为 0。
  2. 所以 a − 2 = 0，b + 3 = 0。
  3. a = 2，b = −3，因此 a − b = 2 − (−3) = 5。
易错点：把 |a − b| 写成 a − b；非负性题只让一部分为 0；最值题忘记“中间区域”；分类讨论漏掉端点。

有理数的运算

高级目标：处理符号讨论、巧算、乘方规律和科学记数法的逆向问题。

核心模型

符号与巧算

  • 符号讨论：含字母的乘方，先分底数为正、为负、为 0。
  • 分组巧算：把相邻项分组，让每组结果相同或抵消。
  • 凑整：利用相反数、倒数、分配律把计算变简单。
  • 幂的规律：负数的幂符号交替，偶次为正、奇次为负。
  • 科学记数法逆向：整数位数 = n + 1，反过来可由位数求 n。
方法

压轴题的切入口

  1. 先观察结构：有没有相反数、倒数、相同因数可以凑整？
  2. 再分组：项数很多时，两两分组或三三分组，找每组的结果。
  3. 最后定符号：先算绝对值，再数负因数个数，确定最终符号。
巧算不是背技巧，而是先观察“哪些项能凑成 0、1 或整十整百”。
例题

3 道综合题

例 1（综合）：计算 1 − 2 + 3 − 4 + … + 99 − 100。

看详细解析
  1. 把相邻两项分组：(1 − 2) + (3 − 4) + … + (99 − 100)。
  2. 每组都是 −1，一共有 50 组。
  3. 所以结果是 50 × (−1) = −50。

例 2（压轴）：已知 a、b 互为相反数，c、d 互为倒数，|m| = 2，求 a + b + cd + m²。

看详细解析
  1. a、b 互为相反数，所以 a + b = 0。
  2. c、d 互为倒数，所以 cd = 1。
  3. |m| = 2，所以 m² = 4。
  4. 原式 = 0 + 1 + 4 = 5。

例 3（提高）：一个数用科学记数法表示为 2.5 × 10ⁿ，且原数是 8 位数，求 n。

看详细解析
  1. 科学记数法的原数整数位数 = n + 1。
  2. 原数是 8 位数，所以 n + 1 = 8。
  3. 解得 n = 7，原数是 25000000。
易错点：分组后符号写错；把 (−2)² 与 −2² 混淆；负因数个数数错；科学记数法的指数与位数搞反。

代数式

高级目标：从图形规律中抽象出含 n 的式子，用整体代入求值，理解公式的来源。

核心模型

规律与整体

  • 图形规律：先数前三个，找“每次增加多少”，再写成 an + b。
  • 整体代入：不求出单个字母，直接把已知整体换进去。
  • 公式变形：把几何公式中的量用字母表示，再代入求值。
  • 数列规律：平方数、三角形数、奇数和，都可以用含 n 的式子表示。
  • 分类讨论：含绝对值或位置不确定时，先分情况再列式。
方法

压轴题的切入口

  1. 先数具体：n = 1、2、3 时各是多少，列成表格。
  2. 再找增量：每次增加的是常数，还是一次式？
  3. 最后验证：把 n = 4 代进去，看是否符合图形。
规律题不要急着写答案，先用 n = 1、2、3 验证；不符合就调整。
例题

3 道综合题

例 1（综合）：用含 n 的式子表示 1 + 3 + 5 + … + (2n − 1)，并验证 n = 10 时的结果。

看详细解析
  1. n = 1：1 = 1²；n = 2：1 + 3 = 4 = 2²；n = 3：1 + 3 + 5 = 9 = 3²。
  2. 规律：前 n 个奇数之和等于 n²。
  3. 当 n = 10 时，1 + 3 + … + 19 = 10² = 100。

例 2（压轴）：已知 x² + x = 3，求 2x² + 2x + 1 的值。

看详细解析
  1. 把 x² + x 看成一个整体。
  2. 2x² + 2x + 1 = 2(x² + x) + 1。
  3. 代入 x² + x = 3：2 × 3 + 1 = 7。

例 3（提高）：用含 n 的式子表示 1 + 2 + 3 + … + n，并求 n = 10 时的值。

看详细解析
  1. n = 1：1；n = 2：1 + 2 = 3；n = 3：1 + 2 + 3 = 6。
  2. 规律：1 + 2 + … + n = n(n + 1)/2。
  3. 当 n = 10 时，10 × 11 ÷ 2 = 55。
易错点：规律题的 n 从 0 还是 1 开始搞错；整体代入时漏乘系数；括号漏写；公式变形时代错位置。

整式的加减

高级目标：处理“与某字母无关”、整式减法、看错符号和整体代入。

核心模型

无关项与整体

  • 无关项：合并后令某字母的系数为 0，求出参数。
  • 整式减法：减去一个多项式，等于加上它的相反数，每一项都变号。
  • 看错符号：把“减去”看成“加上”，结果会整体反号。
  • 整体代入：把 x² + x 或 a + b 看成一个整体。
  • 多项式加减：先加括号，再去括号，注意每一项都要处理。
方法

压轴题的切入口

  1. 先合并：把含同一字母的项合并，写成 Ax² + Bx + C。
  2. 再令系数为 0：“与 x 无关”就是 x²、x 的系数都为 0。
  3. 最后检验：把参数代回，确认结果确实不含该字母。
整式减法最容易漏变号，做完后逐项检查第二项的符号。
例题

3 道综合题

例 1（综合）：若多项式 (2x² + ax − y + 6) − (2bx² − 3x + 5y − 1) 的值与 x 无关，求 a、b。

看详细解析
  1. 去括号合并： (2 − 2b)x² + (a + 3)x − 6y + 7。
  2. 要与 x 无关，x² 和 x 的系数都必须为 0。
  3. 2 − 2b = 0，所以 b = 1；a + 3 = 0，所以 a = −3。

例 2（压轴）：已知 A = 3x² − 2x + 1，B = 2x² + x − 3，求 A − 2B。

看详细解析
  1. 先算 2B = 4x² + 2x − 6。
  2. A − 2B = (3x² − 2x + 1) − (4x² + 2x − 6)。
  3. 去括号：3x² − 2x + 1 − 4x² − 2x + 6。
  4. 合并：−x² − 4x + 7。

例 3（提高）：某同学把“加上 2x² − 3x + 1”看成了“减去”，得到 x² + 2x − 4，求正确结果。

看详细解析
  1. 设原多项式为 A，则 A − (2x² − 3x + 1) = x² + 2x − 4。
  2. 所以 A = x² + 2x − 4 + 2x² − 3x + 1 = 3x² − x − 3。
  3. 正确结果 = A + (2x² − 3x + 1)。
  4. = (3x² − x − 3) + (2x² − 3x + 1) = 5x² − 4x − 2。
易错点：与 x 无关只令一项为 0；整式减法漏变号；看错符号问题不先求原多项式；代入整体时漏乘系数。

一元一次方程

高级目标：含参方程、解的整数性、方案选择和分段计费。

核心模型

参数与方案

  • 含参方程：先化成 ax = b，再讨论 a 是否为 0。
  • 解的条件：已知解，先代入；解是整数，先用参数表示解。
  • 方案选择：两种方案分别列式，令它们相等求临界点，再分情况。
  • 分段计费：先判断落在哪一段，再列方程。
  • 检验：解出的结果要符合实际意义。
方法

压轴题的切入口

  1. 先表示解：把方程化成 x = … 的形式，再看条件。
  2. 再分类：参数出现在系数或分母上时，先确定不能取的值。
  3. 最后比较：方案题先求临界点，再比较临界点两侧。
含参方程先问：未知数的系数能为 0 吗？分母能为 0 吗？
例题

3 道综合题

例 1（综合）：若 x = 2 是方程 3x − (m − 1) = 5 的解，求 m。

看详细解析
  1. 把 x = 2 代入：3 × 2 − (m − 1) = 5。
  2. 6 − m + 1 = 5，即 7 − m = 5。
  3. 解得 m = 2。
  4. 检验：3 × 2 − (2 − 1) = 6 − 1 = 5，成立。

例 2（压轴）：话费方案 A：月租 30 元，每分钟 0.2 元；方案 B：无月租，每分钟 0.4 元。通话多少分钟时两种方案费用相同？

看详细解析
  1. 设通话 x 分钟，A 费用 30 + 0.2x，B 费用 0.4x。
  2. 令它们相等：30 + 0.2x = 0.4x。
  3. 移项得 30 = 0.2x，所以 x = 150。
  4. 此时费用都是 60 元；少于 150 分钟选 B，多于 150 分钟选 A。

例 3（提高）：若关于 x 的方程 (m − 2)x = 5 的解是正整数，求整数 m。

看详细解析
  1. m ≠ 2 时，x = 5/(m − 2)。
  2. 要使 x 是正整数，m − 2 必须是 5 的正因数：1 或 5。
  3. m − 2 = 1 得 m = 3；m − 2 = 5 得 m = 7。
  4. 所以 m = 3 或 7。
易错点：含参方程忘记讨论系数为 0；代入解时符号出错；方案题不写临界点；整数解漏掉负因数或分母条件。

几何图形初步

高级目标：分类讨论点的位置、处理动点与中点、解决钟面角和折叠问题。

核心模型

位置与分类

  • 分类讨论：点在线段上还是延长线上；射线在角内部还是外部。
  • 动点：设运动时间为 t，用含 t 的式子表示线段长度，再列方程。
  • 中点：多个中点时，先分别表示一半，再用和差。
  • 钟面角：分针每分钟 6°，时针每分钟 0.5°。
  • 折叠：折叠前后对应线段、对应角相等。
方法

压轴题的切入口

  1. 先画图：把已知点和未知点都画出来，标清位置关系。
  2. 再分类：位置不确定时，先列出所有可能的位置。
  3. 最后计算：用线段和差、角平分线、中点关系列式。
几何压轴题不怕难，就怕漏情况。先问一句：点还有没有别的位置？
例题

3 道综合题

例 1（综合）：点 C 在直线 AB 上，AB = 5，BC = 3，求 AC 的长度。

看详细解析
  1. C 可能在线段 AB 上，此时 AC = AB − BC = 5 − 3 = 2。
  2. C 也可能在 AB 的延长线上，此时 AC = AB + BC = 5 + 3 = 8。
  3. 所以要分类讨论，AC = 2 或 8。

例 2（压轴）：线段 AB = 10，点 C 在线段 AB 上，AC = 4，M、N 分别是 AC、BC 的中点，求 MN。

看详细解析
  1. AC = 4，BC = 10 − 4 = 6。
  2. M 是 AC 中点，所以 MC = 4 ÷ 2 = 2。
  3. N 是 BC 中点，所以 CN = 6 ÷ 2 = 3。
  4. MN = MC + CN = 2 + 3 = 5。
  5. 发现：MN 恰好等于 AB 的一半。

例 3（提高）：3 点 30 分，钟面上时针与分针的夹角是多少度？

看详细解析
  1. 分针指向 6，是 180°。
  2. 时针在 3 和 4 的正中间，3.5 × 30° = 105°。
  3. 夹角 = 180° − 105° = 75°。
  4. 钟面每大格 30°，分针每分钟 6°，时针每分钟 0.5°。
易错点：只画一种位置；把直线当线段；多个中点时和差关系搞错；钟面角忘记时针也在走；折叠题漏掉对应角。
