第 21 章

一元二次方程

核心问题：一个未知数、最高次数是 2 的方程，怎么解？

21.1

先认清：什么是一元二次方程

只含一个未知数，并且未知数的最高次数是 2 的整式方程，叫做一元二次方程。一般形式是：

ax² + bx + c = 0 (a ≠ 0)
a二次项系数，不能为 0
b一次项系数，可以为 0
c常数项，可以为 0
最容易错：a = 0 时就不是一元二次方程了；判断前先整理成一般形式。
21.2

直接开平方法：x² = p

x² = 4
解x = ±2

把 x² = p 看成抛物线 y = x² 和水平线 y = p 的交点：交点的横坐标就是解。

  • p > 0：两个交点，两个根 x = ±√p
  • p = 0：只有一个交点，x = 0
  • p < 0：没有交点，实数范围内无解
开平方时不要只写正根。“±” 是在提醒你：平方后都等于 p。
21.3

配方法：把缺的一角补上

配方法不是“背步骤”，而是“把一个不完整的正方形补完整”。下面用 x² + 6x − 7 = 0 演示。

静态示意图：x² + 6x + 9 = (x + 3)²。一次项系数 6 的一半是 3，平方是 9。
第 1 / 8 步

先把常数项移到右边

原方程 x² + 6x − 7 = 0，移项得 x² + 6x = 7。左边就是“一个正方形 + 两条长方形”。

x² + 6x − 7 = 0
x² + 6x = 7
x² + 6x + 9 = 7 + 9 = 16
(x + 3)² = 16
x + 3 = ±4
x₁ = 1，x₂ = −7
口诀：一次项系数一半的平方。6 的一半是 3，平方是 9。
21.4

公式法：先看判别式，再代公式

y = x² − 4x + 3
判别式Δ = 4
根的情况两个不相等实根
根x₁ = 1，x₂ = 3
顶点(2, −1)
x = (−b ± √(b² − 4ac)) / 2a

判别式 Δ = b² − 4ac 决定抛物线与 x 轴的交点个数，也就决定方程实根的个数。

  • Δ > 0：两个不相等实根
  • Δ = 0：两个相等实根
  • Δ < 0：没有实根
先化成一般形式，再确定 a、b、c 的符号。代公式时最容易漏掉负号。
21.5

因式分解法：让两个括号相乘等于 0

x² − 5x + 6 = 0
(x − 2)(x − 3) = 0
两根之和5
两根之积6

如果 (x − p)(x − q) = 0，那么 x = p 或 x = q。反过来，已知两根，也可以写出方程。

拓展：x₁ + x₂ = −b/a，x₁x₂ = c/a。这里 a = 1，所以和是 5，积是 6。
把 q 拖到 2，两个根重合，方程变成 (x − 2)² = 0，此时只有一个根（两个相等实根）。
方法

四种解法怎么选？

方法适合的样子关键动作
直接开平方x² = p 或 (x + m)² = p两边开平方，记得写 ±
配方法二次项系数为 1，一次项系数是偶数加“一次项系数一半的平方”
公式法任何一元二次方程先算 Δ = b² − 4ac，再代公式
因式分解容易拆成两个一次因式令每个括号分别等于 0
选择顺序：能直接开平方或因式分解就先做；看不出怎么分解时，用公式法最稳；配方法主要用于理解公式和顶点式。

应用题五步：设未知数 → 找等量关系 → 列方程 → 解并检验 → 写答。

21.6

应用：围一个面积 21 m² 的矩形

x(10 − x) = 21
当前面积21
另一条边7
命中：x = 3，面积 = 21

周长 20 m，说明长 + 宽 = 10 m。设一边为 x，另一边就是 10 − x，面积 A = x(10 − x)。

x(10 − x) = 21
x² − 10x + 21 = 0
(x − 3)(x − 7) = 0
x = 3 或 x = 7

两个答案都对：一边 3 m、另一边 7 m，只是把长和宽交换了。

顺带看一眼：A = −x² + 10x 的最大值在 x = 5，面积 25 m²。这就是第 22 章要学的二次函数最值。
第 22 章

二次函数

核心问题：一条抛物线，为什么由 a、h、k 三个数就决定了？

22.1

从一条抛物线说起

静态图：虚线是完整轨迹，红球在起点。网页版可点击“发射”看小球运动。
y = −x² + 4x

小球的高度 y 和水平距离 x 之间的关系，是一条开口向下的抛物线。最高点在 x = 2，高度 4。

  • 二次函数的图像是抛物线，不是折线
  • 开口向下，说明函数有最大值
  • 顶点就是最高点
a 决定开口方向和胖瘦，(h, k) 决定顶点位置。先记住这句话，后面再拆开看。
22.2

y = ax²：a 到底管什么？

y = x²
a1
开口向上

a > 0 开口向上；a < 0 开口向下。|a| 越大，开口越窄；|a| 越小，开口越宽。

  • 所有 y = ax² 的顶点都在原点 (0, 0)
  • 对称轴都是 y 轴，即 x = 0
  • a 的绝对值越大，抛物线越“瘦”
把 a 从 1 拖到 2，再拖到 0.5，比较开口的胖瘦。
22.3

平移实验台：左加右减，上加下减

当前是基准抛物线 y = x²。
静态图：h = 0、k = 0 时，基准曲线与平移后曲线重合。网页版可拖动 h、k 观察平移。
y = x²
顶点(0, 0)
对称轴x = 0

顶点式：y = a(x − h)² + k，顶点是 (h, k)。

  • k > 0：向上平移；k < 0：向下平移
  • h > 0：向右平移；h < 0：向左平移
注意括号里的符号：向右移 2，写成 (x − 2)²，不是 (x + 2)²。口诀“左加右减”说的是括号里的加减。
22.4

把一般式化成顶点式

y = (x − 2)² − 1
顶点(2, −1)
对称轴x = 2
通用步骤：提二次项系数 → 配一次项系数一半的平方 → 写成完全平方 → 整理常数。
总结

二次函数的三种常用形式

形式表达式一眼能看出
一般式y = ax² + bx + c开口方向、与 y 轴交点 (0, c)
顶点式y = a(x − h)² + k顶点 (h, k)、对称轴 x = h、最值
交点式（拓展）y = a(x − x₁)(x − x₂)与 x 轴交点 (x₁, 0)、(x₂, 0)
求最值、看对称轴，优先化成顶点式；已知图像上三个点，用一般式列方程组；已知与 x 轴的两个交点，用交点式更快（拓展）。
22.5

应用：定价多少，利润最大？

利润 = (售价 − 40)(200 − 2 × 售价)
y = −2(x − 70)² + 1800
当前利润1000 元
最大利润1800 元（售价 70 元）

设售价为 x 元，每件利润是 x − 40，销量是 200 − 2x，所以总利润 y = (x − 40)(200 − 2x)。

y = −2x² + 280x − 8000
y = −2(x² − 140x) − 8000
y = −2(x − 70)² + 1800

开口向下，顶点 (70, 1800) 就是最大值。售价 70 元时，利润最大 1800 元。

最值问题先判断开口方向：a > 0 有最小值，a < 0 有最大值。
理

深入原理：公式不是天上掉下来的

知道“怎么算”还不够，知道“为什么成立”，才不会把公式记混。

原理 1

配方法如何推出求根公式

ax² + bx + c = 0 前提：a ≠ 0
x² + (b/a)x + c/a = 0 两边同时除以 a
x² + (b/a)x = −c/a 常数项移到右边
x² + (b/a)x + (b/2a)² = (b/2a)² − c/a 两边加上“一次项系数一半的平方”
(x + b/2a)² = (b² − 4ac) / (4a²) 左边写成完全平方，右边通分
x + b/2a = ±√(b² − 4ac) / (2a) 两边开平方，别漏 ±
x = (−b ± √(b² − 4ac)) / (2a)

关键只有一句：把左边配成完全平方。左边一旦变成“某个式子的平方”，右边就是一个常数，直接开平方即可。

为什么右边分母是 4a²？因为 (b/2a)² = b²/(4a²)，通分后就是 (b² − 4ac)/(4a²)。

为什么最后可以写成 2a 而不是 2|a|？因为前面有 ±，正负号已经把分母的符号“吸收”掉了。

a ≠ 0 是整个过程的前提：否则不能除以 a，方程也不再是二次方程。
原理 2

判别式为什么能决定根的个数

配方后得到：

(x + b/2a)² = (b² − 4ac) / (4a²)

左边是一个平方，永远 ≥ 0；右边分母 4a² 永远 > 0。所以右边的符号完全由 Δ = b² − 4ac 决定。

  • Δ > 0：右边是正数，开平方有两个相反数 → 两个根
  • Δ = 0：右边是 0，平方等于 0 只有一个值 → 两个相等实根
  • Δ < 0：右边是负数，实数的平方不可能为负 → 没有实根

从图像看，顶点纵坐标是：

k = (4ac − b²) / (4a) = −Δ / (4a)

以 a > 0 为例：Δ > 0 时顶点在 x 轴下方，抛物线穿过 x 轴两次；Δ = 0 时顶点刚好在 x 轴上；Δ < 0 时顶点在 x 轴上方，整条曲线都在 x 轴上方。

代数和几何在这里说的是同一件事：Δ 的符号 = 抛物线与 x 轴交点的个数。
原理 3

因式分解与根与系数的关系

如果两个数相乘等于 0，那么至少有一个数是 0：

AB = 0 → A = 0 或 B = 0

所以只要能写成 a(x − x₁)(x − x₂) = 0，就能直接读出两个根 x₁、x₂。

把它展开，再和 ax² + bx + c 对比：

a(x − x₁)(x − x₂) = ax² − a(x₁ + x₂)x + a x₁x₂
x₁ + x₂ = −b/a，x₁x₂ = c/a

这就是“根与系数的关系”（韦达定理）：

  • 两根之和 = 一次项系数的相反数除以二次项系数
  • 两根之积 = 常数项除以二次项系数

它也解释了十字相乘：要找两个数，使它们的和等于 −b/a，积等于 c/a。

当 a = 1 时最好用：找两个数，和是 −b，积是 c。例如 x² − 5x + 6 = 0，−b = 5，所以找和为 5、积为 6 的两个数：2 和 3。
原理 4

顶点公式为什么是 x = −b/(2a)

y = ax² + bx + c
y = a(x² + (b/a)x) + c 提出二次项系数 a
y = a(x + b/2a)² + c − b²/(4a) 括号内配成完全平方
y = a(x + b/2a)² + (4ac − b²)/(4a)

所以顶点式里的 h = −b/(2a)，k = (4ac − b²)/(4a)。

为什么顶点在 h？因为平方项 a(x − h)² 在括号等于 0 时取得最小（或最大）值，也就是 x = h 的时候。

再往深一层：抛物线关于 x = h 对称。如果它与 x 轴有两个交点，这两个交点一定关于 h 对称，而它们的平均数正是 −b/(2a)。

a > 0 时顶点是最低点，函数有最小值 k；a < 0 时顶点是最高点，函数有最大值 k。
用

日常里的一元二次方程

看到“面积”“乘积”“最高/最低”“平方”，就要警惕：这可能是二次关系。

为什么生活里会出现二次方程？因为很多量是“两个含 x 的量相乘”：面积 = 长 × 宽，利润 = 每件利润 × 销量，路程 = 速度 × 时间。只要其中一个或两个含 x，展开后就会出现 x²。

判断技巧：先找“两个量相乘”的关系，再把它们都用同一个未知数表示。展开后如果出现 x²，就进入二次的世界。
几何 · 面积

用 20 m 篱笆围矩形花园，面积 21 m²

设一边为 x m，另一边就是 10 − x m。

x(10 − x) = 21
x² − 10x + 21 = 0 → (x − 3)(x − 7) = 0

x = 3 或 7：花园是 3 m × 7 m。

周长固定时，面积是二次函数；x = 5 时面积最大，为 25 m²（正方形）。

几何 · 边框

给 20 cm × 30 cm 的照片加一圈等宽相框

相框宽 x cm，加上边框后总尺寸是 (20 + 2x) × (30 + 2x)。若总面积为 1200 cm²：

(20 + 2x)(30 + 2x) = 1200

(x + 30)(x − 5) = 0

喷泉的水柱高度

水柱高度 y（m）与水平距离 x（m）满足 y = −x² + 4x。水柱落回地面时 y = 0。

高度为 3 m 时：−x² + 4x = 3 → x² − 4x + 3 = 0 → x = 1 或 3，说明水柱在 1 m 和 3 m 处都经过 3 m 高。

一块矩形屏幕，长比宽多 2，对角线是 10

高频易错点与练习建议

这些地方错一次，就要在错题本上写一次“错因”。

五个高频错误

  1. 忘记 a ≠ 0：看到 x² 项就以为一定是二次方程。
  2. 开平方漏负根：x² = 9 只写 x = 3，漏掉 x = −3。
  3. 配方只加一边：等式左边加 9，右边也要加 9。
  4. 平移方向记反：向右平移 2，方程里是 (x − 2)²。
  5. 顶点符号写错：y = a(x − h)² + k 的顶点是 (h, k)，不是 (−h, k)。

每天 25 分钟怎么练

  • 先用 5 分钟看一个动图，自己复述“它在变什么”。
  • 再用 10 分钟做 3 道同类题，必须写出 a、b、c。
  • 最后用 10 分钟整理错因：是概念错、符号错，还是计算错。
  • 每周回来看一次“知识串联”表，把方程和图像对上。
  • 不要只背公式：先判断 Δ，再决定要不要代公式。
