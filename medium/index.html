一元二次方程

中级目标：会选解法、会判断根的情况、会用韦达定理、会检验应用题。

知识清单

先把工具摆齐

  • 一般形式：ax² + bx + c = 0，且 a ≠ 0。
  • 四种解法：直接开平方、配方法、公式法、因式分解法。
  • 求根公式：x = (−b ± √(b²−4ac)) / (2a)。
  • 判别式：Δ = b² − 4ac。
  • 韦达定理：x₁ + x₂ = −b/a，x₁x₂ = c/a。
Δ > 0：两个不等实根
Δ = 0：两个相等实根
Δ < 0：没有实根
用韦达定理前，先确认 Δ ≥ 0；用公式前，先把方程整理成一般形式。
方法

常规题的固定动作

  1. 先观察结构：能直接开平方或因式分解就优先；看不出分解时，用公式法最稳。
  2. 含参数先看二次项：二次项系数可能为 0 时，先分情况，再算 Δ。
  3. 韦达定理配合恒等式：x₁²+x₂² = (x₁+x₂)² − 2x₁x₂；1/x₁+1/x₂ = (x₁+x₂)/(x₁x₂)。
  4. 应用题：设未知数 → 找等量关系 → 列方程 → 解并检验 → 写答。
例题

3 道题，从基础到应用

例 1（基础）：解方程 2x² − 5x + 2 = 0。

看详细解析
  1. 确定系数：a = 2，b = −5，c = 2。
  2. 算判别式：Δ = (−5)² − 4×2×2 = 25 − 16 = 9 > 0。
  3. 代入公式：x = (5 ± 3) / 4。
  4. 所以 x₁ = 2，x₂ = 1/2。

例 2（提高）：已知 x₁、x₂ 是 x² − 3x − 2 = 0 的两根，求 x₁² + x₂²。

看详细解析
  1. 先确认有根：Δ = (−3)² − 4×1×(−2) = 17 > 0。
  2. 由韦达定理：x₁ + x₂ = 3，x₁x₂ = −2。
  3. 用恒等式：x₁² + x₂² = (x₁+x₂)² − 2x₁x₂。
  4. 代入：3² − 2×(−2) = 9 + 4 = 13。

例 3（应用）：某商品原价 100 元，连续两次降价后变为 81 元，求平均每次降价的百分率。

看详细解析
  1. 设平均每次降价的百分率为 x。
  2. 列方程：100(1−x)² = 81。
  3. 两边除以 100：(1−x)² = 0.81。
  4. 开平方：1−x = ±0.9，所以 x = 0.1 或 x = 1.9。
  5. 降价率不能超过 100%，舍去 1.9，所以平均每次降价 10%。
易错点：忘记 a ≠ 0；开平方漏负根；配方只在一边加；用韦达定理前不检查 Δ；应用题不检验负根。

二次函数

中级目标：会求解析式、会看图象、会平移、会用顶点求最值。

知识清单

三种形式与图象

  • 一般式：y = ax² + bx + c。
  • 顶点式：y = a(x−h)² + k，顶点 (h,k)。
  • 交点式：y = a(x−x₁)(x−x₂)。
  • 对称轴：x = −b/(2a)。
  • 开口：a > 0 向上，有最小值；a < 0 向下，有最大值。
y = a(x−h)² + k
顶点 (h,k)，对称轴 x = h
求最值、看对称轴，优先化成顶点式；已知与 x 轴交点，用交点式更快。
方法

常规题的固定动作

  1. 求解析式：三点用一般式；顶点用顶点式；两个 x 轴交点用交点式。
  2. 画图看性质：先找顶点和对称轴，再看开口，最后看增减性。
  3. 平移：先化顶点式，再“左加右减、上加下减”。
  4. 与方程、不等式：方程的根是图象与 x 轴交点的横坐标；不等式看图象在 x 轴上方还是下方。
例题

3 道题，从解析式到平移

例 1（基础）：抛物线经过 (0,3)、(1,0)、(3,0)，求它的解析式。

看详细解析
  1. 与 x 轴交于 (1,0)、(3,0)，设交点式 y = a(x−1)(x−3)。
  2. 代入 (0,3)：3 = a×(−1)×(−3) = 3a，所以 a = 1。
  3. 解析式为 y = (x−1)(x−3) = x² − 4x + 3。
  4. 检验：x = 0 时 y = 3，与已知点一致。

例 2（提高）：求抛物线 y = −x² + 4x + 1 的对称轴、顶点和最大值。

看详细解析
  1. a = −1，b = 4，c = 1，对称轴 x = −b/(2a) = 2。
  2. 把 x = 2 代入：y = −4 + 8 + 1 = 5，顶点是 (2,5)。
  3. a = −1 < 0，开口向下，顶点就是最高点。
  4. 所以最大值是 5，在 x = 2 时取得。

例 3（应用）：把抛物线 y = 2x² − 4x + 1 先向右平移 2 个单位，再向上平移 3 个单位，求新解析式。

看详细解析
  1. 先化顶点式：y = 2(x²−2x) + 1 = 2(x−1)² − 1。
  2. 向右平移 2：把 x 换成 x−2，得 y = 2(x−3)² − 1。
  3. 向上平移 3：整体加 3，得 y = 2(x−3)² + 2。
  4. 检查顶点：原来 (1,−1)，平移后 (3,2)，与解析式一致。
易错点：顶点符号写错；平移方向记反；求最值忘记看自变量范围；把交点式里的符号写错。

旋转

中级目标：会找旋转三要素、会画对应点、会判断中心对称图形、会用坐标规律。

知识清单

旋转与中心对称

  • 三要素：旋转中心、旋转方向、旋转角。
  • 性质：旋转前后全等；对应点到中心距离相等；对应点与中心连线的夹角等于旋转角。
  • 中心对称：两个图形绕点旋转 180° 后重合。
  • 中心对称图形：一个图形绕点旋转 180° 后与自身重合。
  • 坐标：关于原点对称，(x,y) → (−x,−y)。
旋转角 = ∠AOA′
OA = OA′
判断中心对称图形，可以想“转 180° 能不能和自己重合”。
方法

常规题的固定动作

  1. 旋转作图：定中心 → 连对应点 → 转相同角度 → 截相等长度。
  2. 找对应点：先找旋转中心和旋转角，再看每个顶点转到哪里。
  3. 中心对称：对应点连线经过对称中心，且被对称中心平分。
  4. 坐标规律：关于原点对称，两个坐标都变相反数。
例题

3 道题，从坐标到辨析

例 1（基础）：点 A(3,−2) 绕原点旋转 180° 后的坐标是什么？正方形绕中心至少转多少度与自身重合？

看详细解析
  1. 绕原点旋转 180° 就是关于原点中心对称，坐标规律是 (x,y) → (−x,−y)。
  2. 所以 A(3,−2) 的对应点是 (−3,2)。
  3. 正方形绕中心转 90° 时，四个顶点互换位置，与自身重合；转 45° 不会。
  4. 所以正方形至少转 90°。

例 2（提高）：钟表从 2:00 走到 2:20，分针转了多少度？时针转了多少度？

看详细解析
  1. 分针每分钟转 360° ÷ 60 = 6°，20 分钟转 120°。
  2. 时针每小时转 30°，每分钟转 0.5°，20 分钟转 10°。
  3. 所以分针转 120°，时针转 10°。

例 3（辨析）：下列图形中，哪些是中心对称图形？平行四边形、等边三角形、圆、正五边形、线段。

看详细解析
  1. 中心对称图形：绕某点旋转 180° 后能与自身重合。
  2. 平行四边形、圆、线段都满足；等边三角形、正五边形不满足。
  3. 所以答案是：平行四边形、圆、线段。
易错点：把中心对称当成轴对称；旋转角找错；坐标规律只变一个符号；把“中心对称”和“中心对称图形”混为一谈。

圆

中级目标：会连半径、作弦心距、用圆周角、判断切线、算弧长和扇形面积。

知识清单

圆里的核心关系

  • 垂径定理：r² = d² + (弦长/2)²。
  • 圆周角：同弧所对的圆周角等于圆心角的一半。
  • 直径：直径所对的圆周角是 90°。
  • 圆内接四边形：对角互补。
  • 切线：切线垂直于过切点的半径；圆外一点引两条切线，切线长相等。
L = nπr / 180
S = nπr² / 360 = ½Lr
见弦作弦心距，见直径想直角，见切点连半径。
方法

常规题的固定动作

  1. 有弦：作弦心距，连半径，构造直角三角形。
  2. 有直径：找 90° 圆周角；有 90° 圆周角，想直径。
  3. 有切线：连圆心和切点，得垂直；证明切线时，看是否经过半径外端。
  4. 求角：优先找同弧所对的圆周角，或用圆内接四边形对角互补。
例题

3 道题，从弦到扇形

例 1（基础）：圆的半径是 5，圆心到弦的距离是 3，求弦长；圆心角是 100°，求同弧所对的圆周角。

看详细解析
  1. 由垂径定理：5² = 3² + (弦长/2)²，所以 (弦长/2)² = 16。
  2. 半弦长 = 4，弦长 = 8。
  3. 同弧所对的圆周角 = 100° ÷ 2 = 50°。

例 2（提高）：半径是 4，圆心角是 120°，求弧长和扇形面积。

看详细解析
  1. 弧长 L = nπr/180 = 120×π×4/180 = 8π/3。
  2. 扇形面积 S = nπr²/360 = 120×π×16/360 = 16π/3。
  3. 检验：S = ½Lr = ½ × 8π/3 × 4 = 16π/3，一致。

例 3（应用）：圆内接四边形 ABCD 中，∠A = 80°，∠B = 95°，求 ∠C 和 ∠D。

看详细解析
  1. 圆内接四边形对角互补：∠A + ∠C = 180°。
  2. 所以 ∠C = 180° − 80° = 100°。
  3. 同理 ∠D = 180° − 95° = 85°。
易错点：把弦心距当半径；半弦写成整弦；看到垂直就说切线；忘记弦所对的圆周角可能有两种情况。

概率初步

中级目标：会判断等可能、会用列表和树状图、会处理放回与不放回、会比较游戏公平性。

知识清单

概率的基本工具

  • 三类事件：必然事件、不可能事件、随机事件。
  • 概率范围：0 ≤ P(A) ≤ 1。
  • 等可能试验：P(A) = 目标结果数 ÷ 所有等可能结果数。
  • 两步试验：用表格或树状图，注意不重不漏。
  • 频率与概率：大量重复试验时，频率会稳定在概率附近。
P(A) = m / n
先问“是不是等可能”，再问“总共多少种，符合条件多少种”。
方法

常规题的固定动作

  1. 一步试验：直接列举所有结果。
  2. 两步试验：用表格或树状图，第一步行、第二步行，或按步骤画树。
  3. 不放回：第二次抽取时，总数和各类数量都会减少。
  4. 公平性：比较双方获胜概率是否相等。
例题

3 道题，从摸球到两位数

例 1（基础）：袋中有 2 个红球、3 个白球，不放回摸两次，求两次都是红球的概率。

看详细解析
  1. 第一次摸红球的概率是 2/5。
  2. 不放回，第二次剩 1 个红球、3 个白球，共 4 个球，概率是 1/4。
  3. P = 2/5 × 1/4 = 1/10。
  4. 检验：总结果 5×4=20，有利结果 2×1=2，P=2/20=1/10。

例 2（提高）：掷两枚均匀骰子，求点数之和为 7 的概率。

看详细解析
  1. 两枚骰子共有 6×6=36 种等可能结果。
  2. 和为 7 的情况有 6 种：(1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)。
  3. 所以 P = 6/36 = 1/6。

例 3（应用）：从 1、2、3、4 中任取两个不同的数字，组成一个两位数，求这个两位数是偶数的概率。

看详细解析
  1. 十位有 4 种选法，个位有 3 种选法，共 4×3=12 个两位数。
  2. 偶数个位只能是 2 或 4，有 2 种选法。
  3. 个位确定后，十位有 3 种选法，所以偶数有 2×3=6 个。
  4. P = 6/12 = 1/2。
易错点：把频率当概率；两枚骰子只数 21 种；不放回时忘记减少总数；不是等可能事件也直接除。
